# How to complete common ePT workflows

[Français](fr/user-guide.md)

Use this guide to find the procedure for your role in ePT 7.6.21.
Menu visibility depends on account privileges and enabled programme features.

## Before you start

Obtain an account from your PT provider. Confirm the participants mapped to your account.
Use the provider's installation URL and assigned role.
A participant is a laboratory, site or tester record. A data manager is an account
that can act for mapped participants.
For account setup or access review, use [user management](user-management.md).

## Run a PT round as an administrator

1. Follow [setup and participant management](training/part1-setup-and-participants.md) to register accounts and participants.
2. Follow [surveys and shipments](training/part2-surveys-and-shipments.md) to create the round and enroll participants.
3. Review collected responses and exceptions using [evaluation and reporting](training/part4-evaluation-and-reports.md).
4. Check generated report content before finalization.
5. Confirm a mapped participant account can download the released report.

## Submit results as a data manager

1. Sign in to the participant portal.
2. Open **PT Result Submission**.
3. Select the correct participant and shipment.
4. Check the displayed deadline and sample identifiers.
5. Enter results and supporting fields using [the participant procedure](training/part3-participant.md).
6. Complete any confirmation step shown by the form.
7. Reopen the response or its status view to confirm the intended values were recorded.

If testing was not performed, use the form's not-tested declaration where available.
Do not substitute a negative test result for a test that was never performed.
If the shipment is closed or a late response awaits approval, contact the PT provider.

## Find reports and account information

| Menu | Task |
| --- | --- |
| Dashboard | Review the account's PT overview |
| PT Result Submission | Find current result-entry work |
| View PT Result → Individual Report | Find a participant's available report |
| View PT Result → Summary Report | Find available summary reports |
| Corrective Actions | Review available corrective-action material |
| CAPA | Open the corrective-action workflow when enabled |
| All Schemes | Review the broader shipment listing |
| Defaulted Schemes | Review the defaulted-shipment listing |
| Manage → My Login Information | Review login-account information |
| Manage → PT Participant Info | Review mapped participant information |
| Manage → Scheme Information | Review scheme information |

PTCC accounts can have additional data-manager and participant management entries.
For missing records, ask the provider to check mappings and enrollment before creating duplicates.

## Verify a report

1. Open the report from the intended participant account.
2. Confirm the participant identifier and shipment code.
3. Compare the reported results with the submitted response.
4. Send discrepancies to the PT provider with the shipment code and participant identifier.

For a practice round, use the [DTS exercise](training/exercises/dts-hiv-serology.md).
For operational faults, use [troubleshooting](troubleshooting.md).
