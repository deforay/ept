# TB All Sites' Results

**Reports → TB: All Sites' Results** builds an Excel workbook for one TB shipment. The workbook has one row per participant, with the result of every sample.

## Generate a workbook

1. Pick the shipment in **Shipment**. The list holds every TB shipment that is not cancelled, newest first.
2. Click **Generate workbook**.
3. Click **Download** next to the workbook.

Each workbook you build stays in the **Workbooks** list until you leave the page.

## Submitted and result columns

| Column | Values |
|---|---|
| Submitted | **Yes**, **Yes (Late)**, **Yes (Not Tested)** or **No**. |
| Satisfactory/Unsatisfactory | **Satisfactory**, **Unsatisfactory**, **Excluded**, **Not Tested**, **Not Submitted** or **Not Evaluated**. |

Only a response that was evaluated and failed shows **Unsatisfactory**.
