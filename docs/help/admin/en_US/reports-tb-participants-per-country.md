# TB Participants per Country

**Reports → TB: Number of Participants per Country** shows how many participants each country has in TB shipments, and how they respond and perform.

The report shows as soon as the page opens. The filters apply as soon as you change them. There is no Get Report button.

## Filters

Click **Expand Filters** to show the filters.

| Filter | What it does | Default |
|---|---|---|
| Shipment date | Includes shipments whose shipment date falls in this range. Click **Clear** in the date picker to include all dates. | Last 3 years |
| Scheme | Shows the TB scheme. This report covers TB only. | TB |
| Shipment | Includes only the shipments you pick. You can pick more than one. The list holds every TB shipment in the date range that is not cancelled. | All shipments in the date range |
| Country, Region, Province, District | Includes only participants in that place. Each filter shows only when participants have that field filled in. | All |

Each active filter shows as a chip next to the **Expand Filters** button.

- Click a chip to open the filter panel on that filter.
- Click **×** on a chip to remove that filter.

Cancelled shipments never show in this report.

## Chart

Each bar is one country. The bar length is the number of participants. The countries with the most participants come first.

## Table

Each row is one country. A participant enrolled in three shipments counts as one participant and three enrolments.

| Column | What it shows |
|---|---|
| Country | The country on the participant record. Participants without a country show as **Not set**, at the end. |
| Participants | The number of participants. |
| Enrolled | The number of enrolments. |
| Responded | The percentage of enrolments that responded, with a bar. Below it, the number of responses out of the number of enrolments. |
| Pass rate | The percentage of evaluated responses that passed, with a bar. Below it, the number passed out of the number evaluated. Shows **Not evaluated yet** before evaluation. |
| Failed | The number of responses that failed. |

Click a column heading to sort by that column.

## Download Excel

**Download Excel** saves the table as an Excel file, with the response rate and the pass rate as percentages. The file uses the filters of the report on screen.
