# Corrective Actions Report

**Reports → Corrective Actions Report** shows how often each corrective action was given to DTS responses. Evaluation gives a corrective action when a response breaks a rule, such as a missing supervisor approval or an expired test kit.

The report shows as soon as the page opens. The filters apply as soon as you change them. There is no Get Report button.

## Which responses count

The report counts DTS responses that were submitted and not excluded. Responses submitted late count. Participants who did not respond never count, even when an older evaluation gave them corrective actions.

Cancelled shipments never show in this report.

## Filters

Click **Expand Filters** to show the filters.

| Filter | What it does | Default |
|---|---|---|
| Shipment date | Includes shipments whose shipment date falls in this range. Click **Clear** in the date picker to include all dates. | Last 3 years |
| Scheme | Shows the DTS scheme. Corrective actions exist for DTS only. | DTS |
| Shipment | Includes only the shipments you pick. You can pick more than one. The list holds every DTS shipment in the date range that is not cancelled. | All shipments in the date range |
| Country, Region, Province, District | Includes only participants in that place. Each filter shows only when participants have that field filled in. | All |

Each active filter shows as a chip next to the **Expand Filters** button.

- Click a chip to open the filter panel on that filter.
- Click **×** on a chip to remove that filter.

## Totals

The four boxes above the table count the responses that match the filters.

| Box | What it shows |
|---|---|
| Shipments | The number of shipments. |
| Responses | The number of responses. Below it, the number of responses that failed. |
| With a corrective action | The number of responses that received at least one corrective action. Below it, the share of all responses. |
| Average score | The average score of the evaluated responses. |

## Corrective actions

Each row is one corrective action. The corrective actions given most often come first.

| Column | What it shows |
|---|---|
| Corrective Action | The text of the corrective action. |
| Responses | The number of responses that received the corrective action, with a bar. Below it, the share of all responses. |
| Participants | The number of participants who received the corrective action. |
| Failed | The number of those responses that failed. |

Click a corrective action to list the responses that received it, under the row. The list shows the participant, the place, the shipment, the score and the result. It shows the 100 newest responses. **Download Excel** gives the full list. Click the corrective action again to hide the list.

## Downloads
