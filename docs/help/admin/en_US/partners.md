# Partners

This page keeps the list of partner organizations. Each partner has a
name, a web link, a sort order and a status.

Open **Configure → Partners**.

## Add a partner

1. Click **Add New Partner**.
2. Enter the **Partner Name**.
3. Optional: enter the partner's **Link**, for example
   `https://ept.example.com/`.
4. Click **Add**.

A new partner is active and goes to the end of the list.

## The partner list

| Column | What it shows |
| --- | --- |
| **Partner Name** | The organization's name |
| **Link** | The partner's web address |
| **Sort Order** | The partner's position in the list |
| **Added Date** | When the partner was added |
| **Status** | **Active** or **Inactive** |

## Change a partner

1. Click **Edit** on the partner's row.
2. Change the **Partner Name** or **Link**.
3. To move the partner, enter a new **Sort Order**. The partners in
   between shift by one place. A number above the last position
   leaves the order unchanged.
4. To hide the partner, set **Status** to **Inactive**.
5. Click **Update**.

The page has no delete button.
