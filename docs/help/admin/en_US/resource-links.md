# Resource Links

The public home page has three Resource Sections. This page sets the
links and files listed under each section.

Open **Configure → Home Page Settings**. Open **Resource Sections**
and click **Manage Resource Links**.

## Add a resource link

1. Click **Add New Resource Link**.
2. Under **Resource Section**, pick the section. **Display Order**
   fills in with the next free position in that section.
3. Under **Type**, choose **Link** or **File**.
4. If you chose **Link**, enter the address under **Link**.
5. If you chose **File**, choose the file under **File**.
6. Enter the **Display Text** that visitors see.
7. Under **Icon**, pick **Document**, **Download**, **External
   Link**, **Image** or **Video**.
8. Optional: change the **Display Order**.
9. Under **Status**, choose **Active**.
10. Click **Add**.

A file must be a JPG, JPEG, PNG, PDF, DOC, DOCX, XLS or XLSX file.

## The resource link list

| Column | What it shows |
| --- | --- |
| **Resource Section** | The section the link appears under |
| **Link** | The address or file |
| **Display Text** | The text visitors see |
| **Icon** | The icon next to the text |
| **Display Order** | The position within the section |
| **Status** | **Active** or **Inactive** |

The home page shows only active links, in **Display Order**.

## Change or hide a resource link

1. Click **Edit** on the link's row.
2. Change the fields. To replace a file, choose a new one. To keep
   the current file, leave **File** empty.
3. Click **Update**.

To hide a link from the home page, set its **Status** to
**Inactive**.

To change the section headings and icons, see
[Home Page Settings](home-config.md).
