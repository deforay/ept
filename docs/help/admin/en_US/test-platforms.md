# Test Platforms

A test platform is a test or instrument that a participant reports
with a SARS-CoV-2 result. Participants pick a platform for each test
on their response form.

Open **Configure → Scheme Config**. In the sidebar, open
**SARS-CoV-2** and click **Test Platforms**.

## Add a test platform

1. Click **Add New Test Platform**.
2. Enter the **Test Platform Name**.
3. Optional: enter a **Short Test Platform Name**.
4. Enter the **Approval Agency**.
5. Under **Scheme**, pick the scheme.
6. Under **Country Approved/Validated**, choose **Yes** or **No**.
7. Optional: fill in **Source Reference**, **Test Platform
   Manufacturer** and **Comments**.
8. Click **Add**.

A new platform is saved as approved.

## Offer a platform for Test 1, 2 or 3

The participant's response form lists, for each test, only the
platforms mapped to that test.

1. On the Test Platforms page, click **Covid-19 Standard Test Platform
   Map**. The button shows when the SARS-CoV-2 scheme is active.
2. Under **Choose Test Number**, pick **Test 1**, **Test 2** or
   **Test 3**.
3. Click a platform name to move it between the two lists. Use
   **Select All** and **Deselect All** to move every platform.
4. Click **Save Selected**.

The map lists only SARS-CoV-2 platforms with **Country
Approved/Validated** set to **Yes**.

## The platform list

| Column | What it shows |
| --- | --- |
| **Test platform Name** | The platform name |
| **Scheme Name** | The scheme the platform belongs to |
| **Test Platform Manufacturer** | The manufacturer |
| **Approval Agency** | The agency that approved the platform |
| **Approved** | **Yes** or **No** |
| **Created On** | When the platform was added |

Use **Approval status** to show all, approved or unapproved
platforms.

## Change a test platform

1. Click **Edit** on the platform's row.
2. Change the fields. **Approved** sets whether the platform counts as
   approved in the list.
3. Click **Update**.

The page has no delete button.
