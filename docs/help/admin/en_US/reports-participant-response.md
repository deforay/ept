# Participant Response Report

**Reports → Participant Response Report** shows how groups of participants respond and perform. A group is a region, a district, a network tier, an affiliation or an enrolled program.

The report shows as soon as the page opens. The filters apply as soon as you change them. There is no Get Report button.

## Filters

Click **Expand Filters** to show the filters.

| Filter | What it does | Default |
|---|---|---|
| Shipment date | Includes shipments whose shipment date falls in this range. Click **Clear** in the date picker to include all dates. | Last 3 years |
| Scheme | Includes shipments of one scheme. | All schemes. If only one scheme is active, that scheme. |

Each active filter shows as a chip next to the **Expand Filters** button.

- Click a chip to open the filter panel on that filter.
- Click **×** on a chip to remove that filter.

Cancelled shipments never show in this report.

## Group by

The **Group by** buttons pick how participants are grouped.

| Button | Groups participants by |
|---|---|
| Region | The region on the participant record. |
| District | The district on the participant record. |
| Network Tier | The network tier on the participant record. |
| Affiliation | The affiliation on the participant record. |
| Enrolled Program | The programs the participant is enrolled in. A participant in two programs counts in both groups. |

Participants without a value are grouped under **Not set**, at the end.

The page remembers the last grouping you picked in this browser.

## Chart

Each bar is one group. The bar splits the group's enrolments into four parts.

| Part | Meaning |
|---|---|
| On time | Submitted results by the due date. |
| Late | Submitted results after the due date. |
| Could not test | Reported that they could not test the panel. |
| Not responded | Did not respond. |

The four parts add up to the number of enrolments. Point at a bar to see the numbers.

The chart shows the first 15 groups of the table. The table lists every group.

## Table

Each row is one group. A participant enrolled in three shipments counts as three enrolments.

| Column | What it shows |
|---|---|
| Group | The group name. The column heading is the grouping, such as **Region**. |
| Participants | The number of participants in the group. |
| Responses | The percentage of enrolments that responded, with a bar. Below it, the number of responses out of the number of enrolments. |
| Late | The number of responses submitted after the due date. |
| Could not test | The number of participants who reported that they could not test. |
| Not responded | The number of enrolments with no response. |
| Pass rate | The percentage of evaluated responses that passed, with a bar. Below it, the number passed out of the number evaluated. Shows **Not evaluated yet** before evaluation. |
| Failed | The number of responses that failed. |
| Excluded | The number of enrolments excluded from scoring. |

The groups with the most enrolments come first.

Click a group to show its shipments under the row. Each shipment shows the same columns, for that group only. Click the group again to hide its shipments.

## Download Excel

**Download Excel** saves the report as an Excel file with two sheets.

| Sheet | Contents |
|---|---|
| Groups | One row per group, with every count and percentage from the table. |
| By shipment | One row per group and shipment. |

The file uses the filters and the grouping of the report on screen.
