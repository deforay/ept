# Feedback Forms

A feedback form is a short set of questions that participants
answer after a shipment is finalized. Each shipment has at most
one form.

The form opens when the shipment is finalized. It stays open for
the number of days you choose.

## Create a feedback form

1. Open **Configure → Feedback Forms**.
2. Click **New feedback form**.
3. Under **Shipment**, pick the shipment. If it already has a
   form, that form opens instead.
4. Under **Who sees this form**, choose **All participants**,
   **Passing only** or **Failing only**.
5. Under **Open for feedback**, choose how many days after
   finalizing the form stays open.
6. Click **Add questions** and pick questions from the question
   library. Use the arrows to change their order.
7. Optional: write an **Introduction** to show above the
   questions.
8. Optional: under **Files to download**, add files that
   participants can download with the form.
9. Click **Save feedback form**.

Saving switches on **Collect Feedback** for the shipment if it is
off.

To start from an earlier form, use **Reuse an earlier form**.
Pick the shipment to copy from, then click **Copy into this
form**. Nothing is saved until you click **Save feedback form**.

## The Feedback Forms list

| Column | What it shows |
| --- | --- |
| **Feedback** | **Opens when finalized**, **Open**, **Closed** or **Switched off** |
| **Feedback deadline** | When the form closes |
| **Questions** | How many questions the form has |
| **Responses** | How many participants answered |

The **Actions** column has **Edit**, **Copy** (use this form for
another shipment) and a button to download the responses as a
spreadsheet.

## A shipment cannot be finalized without its form

If a shipment collects feedback but has no form yet, its
**Finalize** button stays disabled. The shipment row shows **Set
Up Feedback Form**. Create the form, then finalize.

**Switched off** means **Collect Feedback** is off for the
shipment, so participants never see the form.

To add or change the questions themselves, see
[Feedback Questions](feedback-questions.md).
