# Gene Types

A gene type is a gene target that a SARS-CoV-2 test detects. On the
response form, participants pick the gene types they detected in each
sample.

Open **Configure → Scheme Config**. In the sidebar, open
**SARS-CoV-2** and click **Gene Types**.

## Add a gene type

1. Click **Add New Gene Type**.
2. Enter the **GeneType Name**.
3. Under **Scheme**, pick the scheme.
4. Under **Gene Status**, choose **Active** or **Inactive**.
5. Click **Add**.

## The gene type list

| Column | What it shows |
| --- | --- |
| **Gene type Name** | The gene type name |
| **Scheme Name** | The scheme the gene type belongs to |
| **Created On** | When the gene type was added |

## Change a gene type

1. Click **Edit** on the gene type's row.
2. Change the name, scheme or status. If another gene type already
   has the name, the page tells you and clears the field.
3. Click **Update**.

The page has no delete button.
