# SARS-CoV-2 Settings

This page sets how SARS-CoV-2 shipments are tested and scored.

## Scoring

- **Minimum Passing Percentage**: the score a participant needs
  to pass.
- **Allowed Algorithms**: the testing algorithms participants
  can choose, separated by commas.

## Testing options

- **Maximum Tests Allowed**: how many tests a participant can
  report for each sample.
- **No. of Days for Sample Rehydration**: how long participants
  wait between rehydrating and testing. Choose **Allow Same Day
  Testing**, **Testing after 1 day only** or **Testing after 2
  days only**.

## Report metadata

**Report Version** and **Report Effective Date** print in the
footer of every report PDF.

## Recommended test platforms

A response that does not use one of the recommended test
platforms does not pass for that sample.

1. Set up the platforms first, under **SARS-CoV-2 Standard Test
   Platforms**.
2. Under **Recommended TestType**, choose the recommended
   platforms.

Click **Update** to save. Changes apply the next time a shipment
is evaluated.
