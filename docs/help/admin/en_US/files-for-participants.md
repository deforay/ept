# Files For Participants

This page sends files to the participants you choose. Each
participant finds the files under **Downloads** in their account.
ePT does not email the files.

The page has three steps. Nothing is sent until you click
**Distribute Files** in the last step.

## Step 1: Choose the participants

1. Narrow the list with the filters: **Scheme Type**,
   **Shipment**, **Country**, **Region**, **Province**,
   **District** and **Result**.
2. Click **Load Participants**.
3. Untick any participant who must not get the files. Use the
   search box to find one.
4. Click **Next**.

## Step 2: Upload the files

Drop the files on the page, or click to browse. The page lists
the file types it accepts. It rejects other types and names the
files it did not accept.

Click **Next**.

## Step 3: Confirm and send

1. Check the files and the number of recipients.
2. Remove any file you uploaded by mistake, or click **Previous**
   to add more.
3. Click **Distribute Files**.

## Common problems

| Message | What to do |
| --- | --- |
| *No participants match the selected filters* | Loosen the filters and click **Load Participants** again |
| *Please select at least one participant* | Tick at least one participant in step 1 |
| *Please upload at least one file* | Upload a file in step 2 |
| *These files were not accepted (unsupported file type)* | Save the file in an accepted type and upload it again |
