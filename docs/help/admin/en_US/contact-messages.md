# Contact Messages

This page lists the messages sent from the Contact form on the
home page, newest first. ePT saves every message here, even when
it cannot send email.

## Read and answer a message

1. Open **Configure → Contact Messages**.
2. Find the message. Type a name, email address, participant
   code or word from the message in the search box.
3. Read the **Subject** and **Message**.
4. Write to the sender from your own email account, at the
   address under **From**.

ePT also emails each message to the **Administrator Email** set
in **Configure → ePT Global Settings**. Reply to that email to
answer the sender. If a PTCC sends the message while logged in,
the PTCC gets a copy too.

## When email is not working

If ePT cannot send email, contact messages reach no one by email.
The **Dashboard** bar then says how many messages arrived that
nobody was emailed about. Click **Open Contact Messages** in the
bar to read them here.

## Columns

| Column | What it shows |
| --- | --- |
| **Received** | When the message arrived, and the sender's IP address |
| **From** | The sender's name, email address and **Participant Code/ID** |
| **Country** | The country the sender chose |
| **Subject** | The subject the sender wrote |
| **Message** | The message text |
| **Action** | **Create Data Manager login** |

Web addresses in a message show as plain text, for example
`hxxps://example[.]com`. A click cannot open them.

## Add a login for the sender

Click **Create Data Manager login** to open **Add New Data
Manager (Participant Login)**. The sender's email, names, lab and
phone are already filled in. Complete the form and save it. See [Data
Manager form](data-managers-form.md).
