# TB Result of PT Panel per Site

**Reports → TB: Result of PT Panel per Site** lists the result of every participant in each TB shipment.

The report shows as soon as the page opens. The filters apply as soon as you change them. There is no Get Report button.

## Filters

Click **Expand Filters** to show the filters. The report covers TB only, so there is no scheme filter.

| Filter | What it does | Default |
|---|---|---|
| Shipment date | Includes shipments whose shipment date falls in this range. Click **Clear** in the date picker to include all dates. | Last 3 years |
| Shipment | Includes only the shipments you pick. You can pick more than one. The list holds every TB shipment in the date range that is not cancelled. | All shipments in the date range |
| Country, Region, Province, District | Includes only participants in that place. Each filter shows only when participants have that field filled in. | All |

Cancelled shipments never show in this report.

## Results

Each enrolment has exactly one result.

| Result | Meaning |
|---|---|
| Satisfactory | The response passed. |
| Unsatisfactory | The response failed. |
| Excluded | The response was excluded from scoring. |
| Could not test | The participant reported that they could not test the panel. |
| Not responded | The participant did not respond. |
| Not evaluated | The participant responded and the shipment is not evaluated yet. |

The coloured bar above the table shows the share of each result. The buttons above the table narrow the table to one result. Each button shows how many enrolments have that result.

## Table

Each row is one participant in one shipment.

| Column | What it shows |
|---|---|
| Participant | The participant name. Below it, the participant ID and the institute name. |
| Location | The region and the country. |
| Shipment | The shipment code and the shipment date. |
| Score | The score. Empty unless the result is Satisfactory or Unsatisfactory. |
| Result | The result. |

The **Search** box matches the participant name, the participant ID, the institute name, the region, the country and the shipment code.

## Download Excel

**Download Excel** saves the table as an Excel file. The file uses the filters, the result button and the search of the table on screen. It includes every page of the table.
