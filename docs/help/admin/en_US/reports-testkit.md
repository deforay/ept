# Test Kit Report For HIV Serology

**Reports → Test Kit Report For HIV Serology** shows which test kits participants used in their HIV serology (DTS) responses. For each kit, it shows how often the kit was used as test 1, test 2 and test 3, and how the responses that used it performed.

The report shows as soon as the page opens. The filters apply as soon as you change them. There is no Get Report button.

## Which responses count

The report counts DTS responses that were submitted and name at least one test kit. Responses submitted late count. Participants who did not respond or could not test never count.

Cancelled shipments never show in this report.

## Filters

Click **Expand Filters** to show the filters. The report covers DTS only, so there is no scheme filter. If DTS is not active, the page says so.

| Filter | What it does | Default |
|---|---|---|
| Shipment date | Includes shipments whose shipment date falls in this range. Click **Clear** in the date picker to include all dates. | Last 3 years |
| Shipment | Includes only the shipments you pick. You can pick more than one. The list holds every DTS shipment in the date range that is not cancelled. | All shipments in the date range |
| Country, Region, Province, District | Includes only participants in that place. Each filter shows only when participants have that field filled in. | All |

Each active filter shows as a chip next to the **Expand Filters** button.

- Click a chip to open the filter panel on that filter.
- Click **×** on a chip to remove that filter.

The buttons above the table narrow the report to the kits used as one test.

| Button | Counts |
|---|---|
| All tests | Kits used as test 1, test 2 or test 3. |
| Test 1, Test 2, Test 3 | Only kits used as that test. |

## Totals

| Box | What it shows |
|---|---|
| Responses | The number of responses. |
| Participants | The number of participants who sent those responses. |
| Test kits | The number of different test kits. |

## Test kits

Each row is one test kit. The kits used most come first.

| Column | What it shows |
|---|---|
| Test kit | The kit name. A kit that is no longer in the test kit list shows as **Unknown kit**, with its ID. |
| Responses | The number of responses that used the kit, with a bar. Below it, the share of all responses. A response uses up to three kits, so the shares add up to more than 100%. |
| Participants | The number of participants who used the kit. |
| Test 1, Test 2, Test 3 | The number of responses that used the kit as that test. |
| Pass rate | The percentage of evaluated responses that passed, with a bar. Below it, the number passed out of the number evaluated. Shows **Not evaluated yet** before evaluation. |
| Failed | The number of responses that failed. |

The pass rate belongs to the whole response, not to the kit alone. A response can fail for a reason that has nothing to do with the kit.

Click a test kit to list the responses that used it, under the row. The list shows the participant, the place, the shipment, the tests the kit was used for, the score and the result. It shows the 100 newest responses. **Download Excel** gives the full list. Click the test kit again to hide the list.

## Download Excel

**Download Excel** saves an Excel file with two sheets. **Test kits** has one row per kit. **Responses** has one row per response and kit. The file uses the filters and the test button of the report on screen.
