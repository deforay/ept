# EID Settings

This page sets how Early Infant Diagnosis (EID) shipments are
scored.

## Fields

**Passing Score** is the minimum score a participant needs to
pass an EID shipment. Enter a whole number from 1 to 100. Leave
it blank to use the default of 100.

Click **Update** to save.

## After you change the score

The new score applies the next time a shipment is evaluated.
To update a shipment that is already evaluated, evaluate it
again on **Analyze → Evaluate Responses**.
