# Techniques / plateformes EID

Cette page liste les techniques / plateformes de **diagnostic précoce
du nourrisson (EID)** configurées dans le système. Les participants
les choisissent en remplissant leur formulaire de réponse EID.

L'EID est divisé en **deux catégories** (deux onglets sur cette page) :

- **Technique d'extraction EID** : la plateforme d'extraction des
  acides nucléiques.
- **Technique de détection EID** : la plateforme d'amplification /
  de détection.

Les deux sont configurées séparément, car la plupart des laboratoires
les indiquent séparément dans le formulaire de réponse.

## En-tête de la page

- **Ajouter une nouvelle technique / plateforme EID** : présent sur
  chaque onglet. Ouvre le formulaire d'ajout avec la catégorie de
  l'onglet (Extraction ou Détection).

## Colonnes

- **Nom** : le nom de la technique / plateforme.
- **Statut** : *Actif* / *Inactif*. Cliquez sur le statut pour le
  changer (une fenêtre de confirmation s'affiche d'abord). Seules les
  techniques **actives** apparaissent dans la liste du participant.

## Conseils

- **Changez le statut au lieu de supprimer.** Les techniques EID ne
  peuvent pas être supprimées. Le statut *Inactif* les masque de la
  liste du participant sans casser les réponses passées.
- Les listes **Extraction** et **Détection** sont séparées : un nom
  ajouté dans un onglet n'est pas ajouté dans l'autre. Si une
  plateforme fait les deux, ajoutez-la deux fois (une fois par
  catégorie).
- Cliquez sur **Extraction** ou **Détection** pour changer de liste.
- Il n'existe **pas de formulaire de modification** pour les techniques
  EID. Une fois ajouté, le nom ne peut plus changer. Pour renommer,
  passez l'ancienne entrée à *Inactif* et ajoutez une nouvelle entrée
  avec le nom corrigé.
