# Ajouter une technique / plateforme VL

Crée une nouvelle technique / plateforme de charge virale du VIH. Une
fois ajoutée, elle apparaît dans le formulaire de réponse VL des
participants pour toutes les expéditions à venir.

## Champs

- **Nom** *(obligatoire)* : nom complet de la technique / plateforme. Le
  formulaire vérifie les doublons quand vous quittez le champ.
- **Nom abrégé** *(obligatoire)* : libellé plus court, pour les espaces
  réduits. Les doublons sont aussi vérifiés.

## Enregistrement

- **Ajouter** : enregistre et revient à la liste des techniques VL.
- **Annuler** : abandonne les modifications et revient à la liste.

## Conseils

- Utilisez **le fabricant + la gamme de produit** pour le *Nom* (par
  exemple, *Abbott RealTime HIV-1*). C'est ce que les participants
  s'attendent à voir dans leur liste déroulante.
- Gardez le **Nom abrégé** sous environ 20 caractères. Il apparaît dans
  des graphiques et des colonnes de rapport où la place manque.
- Si vous ne savez pas quoi saisir, regardez les techniques existantes
  dans la liste et suivez leur style. La cohérence aide les participants
  à trouver leur kit.
