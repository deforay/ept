# Types de gènes

Un type de gène est une cible génique qu'un test SARS-CoV-2 détecte.
Dans le formulaire de réponse, les participants choisissent les types
de gènes détectés dans chaque échantillon.

Ouvrez **Configurer → Configuration des programmes**. Dans le menu
latéral, ouvrez **SARS-CoV-2** et cliquez sur **Types de gènes**.

## Ajouter un type de gène

1. Cliquez sur **Add New Gene Type**.
2. Saisissez le **Nom du type de gène**.
3. Dans **Programme**, choisissez le programme.
4. Dans **Statut du gène**, choisissez **Actif** ou **Inactif**.
5. Cliquez sur **Ajouter**.

## La liste des types de gènes

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Nom du type de gène** | Le nom du type de gène |
| **Nom du programme** | Le programme auquel le type de gène appartient |
| **Créé le** | La date d'ajout du type de gène |

## Modifier un type de gène

1. Cliquez sur **Edit** dans la ligne du type de gène.
2. Modifiez le nom, le programme ou le statut. Si un autre type de
   gène porte déjà ce nom, la page vous le signale et vide le champ.
3. Cliquez sur **Mettre à jour**.

La page n'a pas de bouton de suppression.
