# Comment configurer un modèle de certificat

ePT imprime chaque certificat annuel sur votre propre maquette de certificat, en y ajoutant les informations de chaque participant. Ce guide configure une maquette.

Chaque programme a besoin de deux maquettes : une pour **Excellence** et une pour **Participation**. Répétez ces étapes pour chacune.

## Étape 1 : Enregistrez votre maquette au format PDF

Utilisez la maquette que vous avez déjà, créée dans Microsoft Word, PowerPoint, Canva ou par un graphiste.

1. Retirez de la maquette toute information qui change d'un participant à l'autre. Cela inclut le nom du participant et l'année. ePT les ajoute.
2. Dans Microsoft Word ou PowerPoint, choisissez **File → Save As** (en français : **Fichier → Enregistrer sous**), puis choisissez **PDF** comme type de fichier.

ePT accepte aussi une image PNG ou JPG de la maquette.

## Étape 2 : Téléversez la maquette

1. Allez dans **Configurer → Modèles de certificats**.
2. Trouvez le programme.
3. Sous **Excellence** ou **Participation**, cliquez sur **Téléverser**.
4. Déposez le PDF sur la zone de téléversement, ou cliquez sur la zone pour choisir le fichier.

L'éditeur s'ouvre avec votre maquette.

## Étape 3 : Placez les informations

1. Sous **Ajouter une information**, cliquez sur **Nom du participant**. Une zone apparaît sur la maquette.
2. Faites glisser la zone à l'endroit où le nom doit figurer.
3. Faites glisser le coin inférieur droit de la zone pour l'élargir à l'espace prévu pour le nom.
4. Réglez la police, la taille, la couleur et l'alignement sous **Zone sélectionnée**.
5. Ajoutez de la même façon chaque autre information affichée sur le certificat, comme **Année des expéditions** ou **Nom du signataire**.

Pour ajouter un texte fixe, identique pour tous les participants, cliquez sur **Autre texte**. Pour mélanger texte et informations dans une même zone, saisissez le texte et utilisez **Insérer une information dans le texte...**.

## Étape 4 : Vérifiez l'aperçu et enregistrez

1. Sous la maquette, choisissez successivement chaque participant de la liste dans **Affichage**. La liste inclut le participant dont le nom est le plus long.
2. Vérifiez que chaque nom tient dans sa zone. Si un nom s'étale sur trop de lignes, élargissez sa zone.
3. Cliquez sur **Aperçu PDF** pour voir les certificats exactement tels qu'ils seront imprimés.
4. Cliquez sur **Sauvegarder**.

Dans **Configurer → Modèles de certificats**, la maquette affiche **Prêt**.

Pour modifier la maquette plus tard, cliquez sur **Placer les informations** sur le modèle.
