# Comment ajouter une expédition

Une **expédition** est un panel d'échantillons de test envoyé aux
participants. Chaque expédition se trouve **dans une enquête PT**.
Avant d'ajouter une expédition, il vous faut donc une enquête PT
pour la contenir.

Ce guide vous accompagne de l'enquête jusqu'à l'expédition envoyée.
Comptez environ 5 minutes.

## Étape 1 : Vérifiez que vous avez une enquête PT

Allez dans **Gérer → Enquête PT**. La liste de toutes les enquêtes
PT de votre système s'affiche.

- Si une enquête existe déjà pour la date souhaitée, vous pouvez y
  ajouter votre nouvelle expédition. Passez à l'**étape 2**.
- Sinon, cliquez sur **Ajouter une nouvelle enquête PT** en haut à
  droite. Choisissez une date et un code, puis enregistrez.

Pas d'inquiétude : l'enquête PT seule n'envoie rien aux
participants. C'est simplement un dossier pour un cycle de tests.

## Étape 2 : Cliquez sur « Ajouter une expédition » à côté de votre enquête

Dans la liste des enquêtes PT, trouvez la ligne de votre enquête.
Dans la colonne **Action**, cliquez sur **Ajouter une expédition**.
La liste des expéditions de cette enquête s'ouvre.

En haut de la liste des expéditions, choisissez le type de test
dans **Type de programme**. Cliquez ensuite sur **New Shipment**.
Le formulaire d'expédition s'ouvre en dessous.

Si votre enquête contient déjà une expédition et que vous voulez en
ajouter une autre (par exemple, envoyer à la même date un panel de
sérologie VIH et un panel de charge virale), choisissez l'autre type
de test et cliquez de nouveau sur **New Shipment**. Une enquête peut
contenir plusieurs expéditions.

## Étape 3 : Remplissez les détails de l'expédition

Vous êtes maintenant sur la page **Ajouter une expédition**. Cet
écran déroute beaucoup d'utilisateurs : il ressemble à une toute
nouvelle tâche, mais ce n'en est pas une. **Vous n'avez pas perdu
votre enquête PT.** Cette page est simplement l'étape suivante.

Remplissez :

- **Programme** : le type de test (par exemple, *Échantillon sur
  tube séché - Sérologie du VIH*).
- **Code de l'expédition** : un code est rempli pour vous. Vous
  pouvez le modifier si vous le souhaitez.
- **Date limite de soumission des résultats** : la dernière date à
  laquelle les participants doivent envoyer leurs résultats.
- **Échantillons** : cliquez sur **+ Échantillon/Contrôle** pour
  ajouter une ligne d'échantillon. Pour chaque échantillon, donnez
  un nom (comme `S1`) et choisissez son **résultat attendu**. La
  plupart des panels comptent 3 à 5 échantillons.

Cliquez sur **Ajouter une expédition** en bas pour enregistrer.

## Étape 4 : Inscrivez les participants à cette expédition

Après l'enregistrement, vous revenez à la liste des expéditions.
Votre nouvelle expédition a un bouton rouge **Inscrire**.
Cliquez dessus.

- À **droite** se trouvent les participants qui **recevront** cette
  expédition. À la première ouverture de la page, les laboratoires
  inscrits au programme y sont déjà.
- À **gauche** se trouvent tous les autres participants actifs.

Cliquez sur le nom d'un participant pour le faire passer de l'autre
côté. Cliquez sur **Inscrire** en bas pour enregistrer.

> **Tout sélectionner** ajoute tous les participants actifs à
> l'expédition. Utilisez-le uniquement si tous les laboratoires
> doivent recevoir cette expédition. Pour changer les participants
> sélectionnés par défaut, consultez le guide *Comment inscrire des
> participants*.

## Étape 5 : Expédiez

Revenez dans **Gérer → Enquête PT**.

Trouvez votre enquête dans la liste. Si tout est prêt, le bouton
**Expédier maintenant** apparaît dans la colonne **Action**.

- Cliquez sur **Expédier maintenant**.
- Une fenêtre de confirmation vous demande si vous êtes sûr.
  Cliquez sur **OK**.
- C'est terminé. L'expédition est maintenant visible pour les
  participants inscrits, qui peuvent commencer à saisir leurs
  résultats.

> **Attention :** l'expédition ne peut pas être annulée. Dès que
> vous cliquez sur Expédier maintenant, les participants voient
> l'expédition et peuvent commencer à répondre. Vérifiez donc
> d'abord vos échantillons et vos inscriptions.
