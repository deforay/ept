# Lots de certificats

Cette page liste tous les lots de certificats, passés et en cours. Pour
délivrer, vérifier ou approuver des certificats, utilisez **Certificats
annuels**. Voir [Certificats annuels](certificates.md).

## Trouver un lot

Filtrez par **Statut** ou par **Plage de dates**. Cliquez sur
**Réinitialiser** pour effacer les filtres.

Chaque ligne affiche le **Nom du lot**, les **Expéditions** qu'il couvre
et le nombre de certificats **Excellence**, **Participation** et
**Ignorés**.

## Statuts des lots

| Statut | Signification |
| --- | --- |
| **En attente** ou **En cours de génération** | Les certificats sont en cours de création |
| **Généré** | Prêt à être vérifié dans Certificats annuels |
| **Approuvé** ou **Distribution en cours** | Les certificats sont en cours de mise à disposition des participants |
| **Distribué** | Les participants peuvent télécharger leurs certificats |
| **Échec** | La génération s'est arrêtée sur une erreur. Ouvrez le lot dans Certificats annuels pour en voir la cause |
| **Rejeté** ou **Annulée** | Le lot a été abandonné |

Un lot en cours se met à jour tout seul sur la page.

## Actions

- **Télécharger le ZIP** ou **Télécharger** enregistre les certificats
  du lot.
- **Ouvrir dans Certificats annuels** ouvre le lot. Vous pouvez alors le
  vérifier, l'approuver ou l'abandonner.
