# Techniques VL / Plateformes

Liste toutes les **techniques / plateformes de charge virale du VIH**
configurées dans le système. Les participants choisissent dans cette
liste quand ils remplissent leur formulaire de réponse VL. Ce qui figure
ici est donc ce qu'ils peuvent choisir.

## En-tête de page

- **Ajouter une nouvelle technique / plateforme VL** : ouvre le
  formulaire *Ajouter*.

## Colonnes

- **Nom** : nom complet de la technique / plateforme (par exemple
  *Abbott RealTime HIV-1*, *Roche COBAS AmpliPrep / TaqMan HIV-1*).
- **Nom abrégé** : libellé plus court, utilisé quand la place manque
  (tableaux de rapport, listes déroulantes).
- **Action** : bouton crayon **Modifier**.

## Conseils

- Utilisez le **Nom abrégé** pour tout ce qui peut apparaître dans une
  colonne étroite ou une légende de graphique. Gardez-le sous environ
  20 caractères.
- Le **Nom** et le **Nom abrégé** sont vérifiés contre les doublons
  pendant la saisie. Vous ne pouvez pas ajouter deux techniques du même
  nom.
- Les techniques VL ne peuvent pas être supprimées depuis cette page. Si
  une technique est retirée du service, modifiez son nom pour la signaler
  (par exemple, *« [retired] Roche COBAS v1 »*). Les anciennes réponses
  correspondent ainsi toujours à la bonne fiche.
- Si vous ne connaissez pas le nom d'une technique, demandez au contact
  du laboratoire le nom du fabricant et du produit. Les noms de cette
  page doivent correspondre à ce que le fabricant imprime sur
  l'appareil.
