# Paramètres de récence du VIH (RTRI)

Cette page définit comment les expéditions de test rapide d'infection
récente (RTRI) sont notées.

## Notation

- **Score minimal de réussite** : le score total qu'un participant doit
  obtenir pour réussir.
- **Score du panel/de l'expédition** et **Score de documentation** : la
  répartition du score total entre les résultats du panel et la
  documentation. Les deux parties forment le score total.

## Options de test

Le **Nombre de jours pour la réhydratation de l'échantillon** définit le
délai que les participants respectent entre la réhydratation et le test.
Choisissez **Permettre les tests le jour même**, **Test après 1 jour
seulement** ou **Test après 2 jours seulement**.

## Métadonnées du rapport

La **Version du rapport** et la **Date d'entrée en vigueur du rapport**
s'impriment dans le pied de page de chaque rapport PDF.

Cliquez sur **Mettre à jour** pour enregistrer. Les modifications
s'appliquent à la prochaine évaluation d'une expédition.
