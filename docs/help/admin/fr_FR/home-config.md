# Réglages de la page d’accueil

Cette page permet de personnaliser la **page d'accueil publique**.
Les participants et les visiteurs la voient à l'adresse `/` avant
de se connecter.

Le menu latéral liste les cinq sections. Cliquez sur le nom d'une
section pour y aller. Saisissez du texte dans **Rechercher dans les
paramètres** pour n'afficher que les champs dont le libellé
correspond. **Développer tout** et **Tout réduire** ouvrent ou
ferment toutes les sections.

## Contenu de la bannière principale

La bannière principale est le grand bloc en haut de la page
d'accueil.

- **Ligne 1 (Titre principal)** : le titre le plus grand.
- **Ligne 2 (Sous-titre)** : le titre secondaire, sous le titre
  principal.
- **Ligne 3 (Description)** : une description plus longue ou une
  phrase d'appel à l'action.
- **URL de la vidéo** : lien YouTube ou vidéo facultatif, intégré
  sous le texte de la bannière.
- **Titre de la page** : le texte affiché dans l'onglet du
  navigateur.
- **URL du lien supplémentaire** + **Texte de lien
  supplémentaire** : un bouton de lien en plus, à côté de la
  bannière (par exemple *« Télécharger le guide de l'utilisateur »*
  vers un PDF). Les deux champs vont ensemble. Laissez les deux
  vides pour masquer le bouton.

## Image de la bannière de la page d'accueil

Téléversez la grande image placée derrière le texte de la
bannière.

- **Banner Image** : taille recommandée d'environ
  **1301×531 px**, en JPG, PNG ou GIF.
- Choisissez une image large et peu contrastée pour que le texte
  de la bannière reste lisible.

## Sections ressources

Trois cartes configurables s'affichent sur la page d'accueil.
Chaque carte a une icône et un titre.

- **Section Ressources 1 / 2 / 3 — Icône** : choisissez une icône
  dans le sélecteur d'icônes intégré (le petit bouton *Icône* ouvre
  une fenêtre avec recherche). L'icône est enregistrée sous forme
  de nom de classe (par exemple `bx bx-file`, `bi bi-book-half`).
- **Section Ressources 1 / 2 / 3 — Texte d’en-tête de section** :
  le titre affiché sur la carte.

Pour définir les **liens** sous le titre de chaque carte, utilisez
le bouton **Gérer les liens vers les ressources** de cette page. Il
ouvre une page séparée pour les liens.

## Logos de la page d'accueil

Deux logos d'en-tête s'affichent côte à côte sur la page
d'accueil.

- **Logo 1 (à gauche)** / **Logo 2 (à droite)** : taille
  recommandée d'environ **80×80 px** pour les deux.
- Utile quand votre programme partage son identité visuelle avec
  un partenaire ou un ministère : le logo de gauche pour le
  programme, celui de droite pour le partenaire.

## Foire aux questions (FAQ)

- Un tableau simple, avec ajout et suppression de lignes, pour les
  paires question/réponse affichées dans la section FAQ de la page
  d'accueil.
- Cliquez sur **+** pour ajouter une ligne et sur **-** pour en
  supprimer une. Chaque ligne contient une question et sa réponse.
- Les lignes sont enregistrées dans l'ordre où vous les placez.
  Pour l'instant, pour changer l'ordre, supprimez puis ajoutez de
  nouveau les lignes.

## Enregistrer

Le bouton **Mettre à jour** enregistre tout le formulaire, y
compris les images téléversées. Les champs obligatoires sont
marqués d'un `*`.

## Conseils

- Après un changement de logo ou d'image de bannière, **forcez
  l'actualisation** (Ctrl+Maj+R) de la page d'accueil pour voir la
  nouvelle image. Les navigateurs gardent souvent les images en
  cache.
- Utilisez la même famille d'icônes pour les trois sections
  ressources, pour un rendu cohérent (toutes en `bx-*`, toutes en
  `bi-*`, etc.).
- Gardez une **Description** courte dans la bannière. Une longue
  description passe à la ligne et pousse le reste de la page vers
  le bas sur les petits écrans.
- Le tableau FAQ n'a pas de limite. Au-delà de 8 questions
  environ, la page d'accueil paraît souvent encombrée.
