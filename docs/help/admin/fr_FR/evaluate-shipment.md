# Afficher / Réévaluer l'expédition

Vous arrivez sur cette page en cliquant sur **Voir** pour une
expédition dans **Évaluer l'enquête PT**. Elle affiche la réponse de
chaque participant pour cette expédition. Depuis cette page, vous
pouvez :

- Recalculer les scores de toute l'expédition.
- Modifier ou changer le résultat d'un participant.
- Joindre un fichier d'action corrective.
- Rédiger un commentaire visible par tous les participants.

## En haut de la page

- **Vous êtes en train d'évaluer** *(code de l'expédition)* :
  indique l'expédition affichée.
- **Réévaluer** *(bouton rouge)* : lance un nouveau calcul des
  scores pour cette expédition. La page se recharge une fois la tâche
  mise en file d'attente. Désactivé une fois l'expédition finalisée.
- **Retour** : revient à **Évaluer l'enquête PT**.
- Un petit tableau affiche le **Type de programme**, le **Code de
  l'enquête PT** et la **Date**.

## Fichiers d'action corrective et commentaire commun

Juste sous l'en-tête se trouve un petit formulaire. Les deux champs
s'appliquent à **tous** les participants de cette expédition et
apparaissent tous les deux dans les rapports finaux.

### Fichiers d'actions correctives

Un fichier (généralement un PDF) destiné aux participants qui n'ont
pas réussi. Il explique la marche à suivre.

- Cliquez sur le bouton de sélection de fichier pour choisir un
  fichier sur votre ordinateur.
- Un seul fichier est conservé par expédition. Le téléversement d'un
  nouveau fichier remplace l'ancien.
- Un bouton de téléchargement **Action corrective** apparaît à côté
  du rapport du participant. Il reçoit ainsi ces consignes avec son
  résultat.
- Pour retirer le fichier, téléversez un nouveau fichier à sa place.

### Commentaire pour tous les participants de cette expédition

Une note libre qui apparaît sur le rapport de chaque participant.
Usages courants :

- Expliquer un problème avec un échantillon.
- Résumer les résultats de l'ensemble des participants.
- Signaler un problème connu avec le panel.

La zone de texte affiche toujours le commentaire enregistré. Un
nouvel enregistrement remplace l'ancien commentaire : il n'y a qu'un
commentaire par expédition. Si vous devez conserver l'ancien texte,
copiez-le d'abord.

### Mettre à jour le fichier et le commentaire

Un seul bouton enregistre les deux champs ensemble. Vous pouvez
enregistrer le commentaire seul, sans choisir de fichier. Vous pouvez
modifier et enregistrer autant de fois que nécessaire, jusqu'à la
finalisation de l'expédition.

## Afficher uniquement les résultats modifiés

Dans les filtres au-dessus du tableau, réglez **Remplacement manuel
uniquement** pour afficher uniquement les lignes que vous avez
modifiées à la main.
C'est utile pour une dernière vérification avant de générer les
rapports.

## Tableau des participants

Une ligne par participant, avec ces colonnes :

- **Participant/testeur** : nom et ID du laboratoire.
- **Score de réponse** : score calculé à partir des résultats des
  tests.
- **Score de documentation** : score calculé à partir des questions
  de documentation.
- **Résultat** : Réussi, Échec ou Exclu. Les lignes que vous avez
  modifiées à la main sont clairement signalées.
- **État de la réponse** : indique si le participant a répondu.
- **Répondu le** : date de la soumission.
- **Dernière modification** : date de la dernière modification de la
  ligne.
- **Action** : les boutons de chaque ligne (voir ci-dessous).

## Boutons d'action de chaque ligne

- **Modifier** : ouvre le formulaire de réponse du participant pour
  corriger à sa place des fautes de frappe ou des erreurs de saisie
  évidentes. Vos modifications sont signalées comme manuelles.
- **Supprimer** : efface la réponse du participant pour qu'il puisse
  la soumettre de nouveau. Une confirmation vous est demandée.
- **Télécharger l'action corrective** : affiché sur une ligne en
  échec qui a un fichier d'action corrective.
- **Approuver la soumission tardive** et **Rejeter** : affichés sur
  une réponse envoyée après la date limite et qui attend votre
  décision.

## Examiner une soumission tardive

Une réponse commencée avant la date limite et soumise après celle-ci
est mise en attente d'examen.

1. Ouvrez les filtres et réglez **Statut de la réponse** sur
   **Soumission tardive (en attente d'approbation)**.
2. Cliquez sur **Modifier** dans la ligne pour vérifier la réponse.
3. Cliquez sur **Approuver la soumission tardive** pour la prendre en
   compte, ou sur **Rejeter** pour l'écarter. Vous pouvez encore
   approuver plus tard une réponse rejetée.
4. Évaluez de nouveau l'expédition pour que les scores tiennent
   compte de la décision.

## Conseils

- **Réévaluez après chaque modification.** Modifier une ligne ou
  changer un résultat ne recalcule pas à lui seul les scores de toute
  l'expédition. Cliquez sur **Réévaluer** pour que les totaux de la
  page précédente correspondent.
- **Utilisez le commentaire et le fichier d'action corrective**
  lorsque de nombreux participants ont eu des difficultés. Les deux
  apparaissent dans les PDF qu'ils reçoivent.
- **Après la finalisation, cette page est en lecture seule.**
  Réévaluer est désactivé et vos modifications n'atteignent plus les
  participants.
