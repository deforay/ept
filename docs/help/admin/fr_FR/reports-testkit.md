# Rapport sur le kit de test pour la sérologie VIH

**Rapports → Rapport sur le kit de test pour la sérologie VIH** indique quels kits de test les participants ont utilisés dans leurs réponses de sérologie VIH (DTS). Pour chaque kit, il indique combien de fois le kit a servi de test 1, test 2 et test 3, et les performances des réponses qui l'ont utilisé.

Le rapport s'affiche dès l'ouverture de la page. Les filtres s'appliquent dès que vous les modifiez. Il n'y a pas de bouton Obtenir un rapport.

## Réponses prises en compte

Le rapport compte les réponses DTS soumises qui indiquent au moins un kit de test. Les réponses tardives comptent. Les participants qui n'ont pas répondu ou qui n'ont pas pu tester ne comptent jamais.

Les expéditions annulées n'apparaissent jamais dans ce rapport.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres. Le rapport couvre uniquement le DTS. Il n'y a donc pas de filtre de programme. Si le DTS n'est pas actif, la page l'indique.

| Filtre | Effet | Par défaut |
|---|---|---|
| Date d'expédition | Inclut les expéditions dont la date d'expédition est dans cette période. Cliquez sur **Effacer** dans le sélecteur de dates pour inclure toutes les dates. | 3 dernières années |
| Expédition | Inclut uniquement les expéditions choisies. Vous pouvez en choisir plusieurs. La liste contient toutes les expéditions DTS non annulées de la période. | Toutes les expéditions de la période |
| Pays, Région, Province, District | Inclut uniquement les participants de ce lieu. Chaque filtre s'affiche seulement si des participants ont ce champ renseigné. | Tout |

Chaque filtre actif s'affiche sous forme d'étiquette à côté du bouton **Afficher les filtres**.

- Cliquez sur une étiquette pour ouvrir le panneau des filtres sur ce filtre.
- Cliquez sur **×** sur une étiquette pour retirer ce filtre.

Les boutons au-dessus du tableau limitent le rapport aux kits utilisés pour un seul test.

| Bouton | Compte |
|---|---|
| Tous les tests | Les kits utilisés comme test 1, test 2 ou test 3. |
| Test 1, Test 2, Test 3 | Uniquement les kits utilisés pour ce test. |

## Totaux

| Encadré | Contenu |
|---|---|
| Réponses | Le nombre de réponses. |
| Participants | Le nombre de participants qui ont envoyé ces réponses. |
| Kits de test | Le nombre de kits de test différents. |

## Kits de test

Chaque ligne correspond à un kit de test. Les kits les plus utilisés apparaissent en premier.

| Colonne | Contenu |
|---|---|
| Kit de test | Le nom du kit. Un kit qui ne figure plus dans la liste des kits de test apparaît sous **Kit inconnu**, avec son ID. |
| Réponses | Le nombre de réponses qui ont utilisé le kit, avec une barre. En dessous, la part de l'ensemble des réponses. Une réponse utilise jusqu'à trois kits. La somme des parts dépasse donc 100 %. |
| Participants | Le nombre de participants qui ont utilisé le kit. |
| Test 1, Test 2, Test 3 | Le nombre de réponses qui ont utilisé le kit pour ce test. |
| Taux de réussite | Le pourcentage de réponses évaluées qui ont réussi, avec une barre. En dessous, le nombre de réussites sur le nombre de réponses évaluées. Affiche **Pas encore évalué** avant l'évaluation. |
| Échec | Le nombre de réponses en échec. |

Le taux de réussite concerne la réponse entière, pas le kit seul. Une réponse peut échouer pour une raison sans rapport avec le kit.

Cliquez sur un kit de test pour afficher, sous la ligne, les réponses qui l'ont utilisé. La liste indique le participant, le lieu, l'expédition, les tests réalisés avec le kit, le score et le résultat. Elle affiche les 100 réponses les plus récentes. **Télécharger Excel** fournit la liste complète. Cliquez de nouveau sur le kit de test pour masquer la liste.

## Télécharger Excel

**Télécharger Excel** enregistre un fichier Excel avec deux feuilles. **Kits de test** contient une ligne par kit. **Réponses** contient une ligne par réponse et par kit. Le fichier reprend les filtres et le bouton de test du rapport affiché.
