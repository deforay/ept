# Partenaires

Cette page tient la liste des organisations partenaires. Chaque
partenaire a un nom, un lien web, un ordre de tri et un statut.

Ouvrez **Configurer → Partenaires**.

## Ajouter un partenaire

1. Cliquez sur **Ajouter un nouveau partenaire**.
2. Saisissez le **Nom du partenaire**.
3. Facultatif : saisissez le **Lien** du partenaire, par exemple
   `https://ept.example.com/`.
4. Cliquez sur **Ajouter**.

Un nouveau partenaire est actif et se place en fin de liste.

## La liste des partenaires

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Nom du partenaire** | Le nom de l'organisation |
| **Lien** | L'adresse web du partenaire |
| **Ordre de tri** | La position du partenaire dans la liste |
| **Date d'ajout** | La date d'ajout du partenaire |
| **Statut** | **Actif** ou **Inactif** |

## Modifier un partenaire

1. Cliquez sur **Edit** dans la ligne du partenaire.
2. Modifiez le **Nom du partenaire** ou le **Lien**.
3. Pour déplacer le partenaire, saisissez un nouvel **Ordre de tri**.
   Les partenaires situés entre les deux positions se décalent d'une
   place. Un nombre supérieur à la dernière position ne change pas
   l'ordre.
4. Pour masquer le partenaire, réglez **Statut** sur **Inactif**.
5. Cliquez sur **Mettre à jour**.

La page n'a pas de bouton de suppression.
