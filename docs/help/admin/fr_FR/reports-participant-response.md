# Rapport sur les réponses des participants

**Rapports → Rapport sur les réponses des participants** montre comment des groupes de participants répondent et quels sont leurs résultats. Un groupe est une région, un district, un niveau du réseau, une affiliation ou un programme d'inscription.

Le rapport s'affiche dès l'ouverture de la page. Les filtres s'appliquent dès que vous les modifiez. Il n'y a pas de bouton **Obtenir un rapport**.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres.

| Filtre | Effet | Valeur par défaut |
|---|---|---|
| Date d'expédition | Inclut les expéditions dont la date d'expédition se trouve dans cette période. Cliquez sur **Effacer** dans le sélecteur de dates pour inclure toutes les dates. | 3 dernières années |
| Programme | Inclut les expéditions d'un programme. | Tous les programmes. Si un seul programme est actif, ce programme. |

Chaque filtre actif s'affiche sous forme d'étiquette à côté du bouton **Afficher les filtres**.

- Cliquez sur une étiquette pour ouvrir le panneau des filtres sur ce filtre.
- Cliquez sur **×** sur une étiquette pour retirer ce filtre.

Les expéditions annulées n'apparaissent jamais dans ce rapport.

## Regrouper par

Les boutons **Regrouper par** déterminent comment les participants sont regroupés.

| Bouton | Regroupe les participants par |
|---|---|
| Région | La région indiquée dans la fiche du participant. |
| District | Le district indiqué dans la fiche du participant. |
| Niveau du réseau | Le niveau du réseau indiqué dans la fiche du participant. |
| Affiliation | L'affiliation indiquée dans la fiche du participant. |
| Programme | Les programmes auxquels le participant est inscrit. Un participant inscrit à deux programmes compte dans les deux groupes. |

Les participants sans valeur sont regroupés sous **Non défini**, à la fin.

La page retient, dans ce navigateur, le dernier regroupement choisi.

## Graphique

Chaque barre correspond à un groupe. La barre divise les inscriptions du groupe en quatre parties.

| Partie | Signification |
|---|---|
| Dans les délais | Résultats soumis avant la date limite. |
| Tardives | Résultats soumis après la date limite. |
| N'a pas pu tester | A indiqué ne pas avoir pu tester le panel. |
| Pas de réponse | N'a pas répondu. |

La somme des quatre parties est égale au nombre d'inscriptions. Pointez une barre pour voir les chiffres.

Le graphique affiche les 15 premiers groupes du tableau. Le tableau liste tous les groupes.

## Tableau

Chaque ligne correspond à un groupe. Un participant inscrit à trois expéditions compte pour trois inscriptions.

| Colonne | Contenu |
|---|---|
| Groupe | Le nom du groupe. L'en-tête de la colonne est le regroupement choisi, par exemple **Région**. |
| Participants | Le nombre de participants du groupe. |
| Réponses | Le pourcentage d'inscriptions qui ont donné lieu à une réponse, avec une barre. En dessous, le nombre de réponses sur le nombre d'inscriptions. |
| Tardives | Le nombre de réponses soumises après la date limite. |
| N'a pas pu tester | Le nombre de participants qui ont indiqué ne pas avoir pu tester. |
| Pas de réponse | Le nombre d'inscriptions sans réponse. |
| Taux de réussite | Le pourcentage de réponses évaluées qui ont réussi, avec une barre. En dessous, le nombre de réussites sur le nombre de réponses évaluées. Affiche **Pas encore évalué** avant l'évaluation. |
| Échec | Le nombre de réponses en échec. |
| Exclu | Le nombre d'inscriptions exclues de la notation. |

Les groupes qui ont le plus d'inscriptions apparaissent en premier.

Cliquez sur un groupe pour afficher ses expéditions sous la ligne. Chaque expédition affiche les mêmes colonnes, pour ce groupe uniquement. Cliquez de nouveau sur le groupe pour masquer ses expéditions.

## Télécharger Excel

**Télécharger Excel** enregistre le rapport dans un fichier Excel avec deux feuilles.

| Feuille | Contenu |
|---|---|
| Groupes | Une ligne par groupe, avec tous les totaux et pourcentages du tableau. |
| Par expédition | Une ligne par groupe et par expédition. |

Le fichier utilise les filtres et le regroupement du rapport affiché à l'écran.
