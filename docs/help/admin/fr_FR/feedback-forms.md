# Formulaires de feedback

Un formulaire de feedback est une courte série de questions auxquelles
les participants répondent après la finalisation d'une expédition.
Chaque expédition a au plus un formulaire.

Le formulaire s'ouvre à la finalisation de l'expédition. Il reste ouvert
pendant le nombre de jours que vous choisissez.

## Créer un formulaire de feedback

1. Ouvrez **Configurer → Formulaires de feedback**.
2. Cliquez sur **Nouveau formulaire de feedback**.
3. Dans **Expédition**, choisissez l'expédition. Si elle a déjà un
   formulaire, ce formulaire s'ouvre à la place.
4. Dans **Qui voit ce formulaire**, choisissez **Tous les
   participants**, **Réussis uniquement** ou **Échecs uniquement**.
5. Dans **Ouvert au feedback**, choisissez le nombre de jours pendant
   lesquels le formulaire reste ouvert après la finalisation.
6. Cliquez sur **Ajouter des questions** et choisissez des questions
   dans la bibliothèque de questions. Utilisez les flèches pour changer
   leur ordre.
7. Facultatif : rédigez une **Introduction** à afficher au-dessus des
   questions.
8. Facultatif : dans **Fichiers à télécharger**, ajoutez des fichiers que
   les participants peuvent télécharger avec le formulaire.
9. Cliquez sur **Enregistrer le formulaire de feedback**.

L'enregistrement active **Recueillir le feedback** pour l'expédition
s'il est désactivé.

Pour partir d'un formulaire précédent, utilisez **Réutiliser un
formulaire précédent**. Choisissez l'expédition à copier, puis cliquez
sur **Copier dans ce formulaire**. Rien n'est enregistré tant que vous
ne cliquez pas sur **Enregistrer le formulaire de feedback**.

## La liste des formulaires de feedback

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Retour d'information** | **S'ouvre à la finalisation**, **Ouvrir**, **Clôturé** ou **Désactivé** |
| **Date limite du feedback** | La date de fermeture du formulaire |
| **Questions** | Le nombre de questions du formulaire |
| **Réponses** | Le nombre de participants qui ont répondu |

La colonne **Actions** contient **Modifier**, **Copier** (utiliser ce
formulaire pour une autre expédition) et un bouton qui télécharge les
réponses dans une feuille de calcul.

## Une expédition ne peut pas être finalisée sans son formulaire

Si une expédition recueille le feedback mais n'a pas encore de
formulaire, son bouton **Finaliser** reste désactivé. La ligne de
l'expédition affiche **Configurer le formulaire de feedback**. Créez le
formulaire, puis finalisez.

**Désactivé** signifie que **Recueillir le feedback** est désactivé pour
l'expédition. Les participants ne voient donc jamais le formulaire.

Pour ajouter ou modifier les questions elles-mêmes, voir
[Questions de feedback](feedback-questions.md).
