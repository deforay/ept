# TB : résultat du panel de PT par site

**Rapports → TB : Résultat du panel de PT par site** liste le résultat de chaque participant dans chaque expédition TB.

Le rapport s'affiche dès l'ouverture de la page. Les filtres s'appliquent dès que vous les modifiez. Il n'y a pas de bouton Obtenir un rapport.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres. Le rapport couvre uniquement la TB. Il n'y a donc pas de filtre de programme.

| Filtre | Effet | Par défaut |
|---|---|---|
| Date d'expédition | Inclut les expéditions dont la date d'expédition est dans cette période. Cliquez sur **Effacer** dans le sélecteur de dates pour inclure toutes les dates. | 3 dernières années |
| Expédition | Inclut uniquement les expéditions choisies. Vous pouvez en choisir plusieurs. La liste contient toutes les expéditions TB non annulées de la période. | Toutes les expéditions de la période |
| Pays, Région, Province, District | Inclut uniquement les participants de ce lieu. Chaque filtre s'affiche seulement si des participants ont ce champ renseigné. | Tout |

Les expéditions annulées n'apparaissent jamais dans ce rapport.

## Résultats

Chaque inscription a exactement un résultat.

| Résultat | Signification |
|---|---|
| Satisfaisant | La réponse a réussi. |
| Insatisfaisant | La réponse est en échec. |
| Exclu | La réponse a été exclue de la notation. |
| N'a pas pu tester | Le participant a signalé qu'il n'a pas pu tester le panel. |
| Pas de réponse | Le participant n'a pas répondu. |
| Non évalué | Le participant a répondu et l'expédition n'est pas encore évaluée. |

La barre colorée au-dessus du tableau montre la part de chaque résultat. Les boutons au-dessus du tableau limitent le tableau à un seul résultat. Chaque bouton indique le nombre d'inscriptions qui ont ce résultat.

## Tableau

Chaque ligne correspond à un participant dans une expédition.

| Colonne | Contenu |
|---|---|
| Participant | Le nom du participant. En dessous, l'ID du participant et le nom de l'institut. |
| Localisation | La région et le pays. |
| Expédition | Le code et la date de l'expédition. |
| Score | Le score. Vide sauf si le résultat est Satisfaisant ou Insatisfaisant. |
| Résultat | Le résultat. |

La zone **Rechercher** cherche dans le nom du participant, l'ID du participant, le nom de l'institut, la région, le pays et le code de l'expédition.

## Télécharger Excel

**Télécharger Excel** enregistre le tableau dans un fichier Excel. Le fichier reprend les filtres, le bouton de résultat et la recherche du tableau affiché. Il contient toutes les pages du tableau.
