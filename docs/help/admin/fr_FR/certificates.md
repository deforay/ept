# Certificats annuels

Cette page délivre le certificat annuel de chaque participant pour
chaque programme. Utilisez-la une fois que toutes les expéditions de
l'année sont finalisées.

La page affiche une étape à la fois. Elle n'ouvre l'étape suivante que
lorsque l'étape en cours est terminée. Si vous quittez la page, elle se
rouvre à la même étape à votre retour.

Pour la marche à suivre complète, voir
[Comment délivrer les certificats annuels](guides/issue-annual-certificates.md).

## Les six étapes

1. **Choisissez les expéditions.** Choisissez l'**Année** et décochez
   toute expédition que les certificats ne doivent pas couvrir.
2. **Vérifiez les modèles.** Chaque programme a besoin d'un modèle
   Excellence et d'un modèle Participation, avec le nom du participant
   placé.
3. **Vérifiez qui reçoit quel certificat.** Vérifiez les nombres et les
   participants qui ne reçoivent aucun certificat.
4. **Générez.** Attendez quelques minutes. Vous pouvez quitter la page.
5. **Vérifiez et approuvez.** Ouvrez quelques certificats, puis cliquez
   sur **Approuver et mettre à disposition des participants**.
6. **Terminé.** Les participants téléchargent leur certificat dans
   **Téléchargements**, dans leur compte. ePT ne leur envoie pas
   d'e-mail.

## Qui reçoit quel certificat

- **Excellence** : a réussi toutes les expéditions cochées du programme.
- **Participation** : a répondu à toutes les expéditions cochées, sans
  toutes les réussir.
- **Aucun certificat** : a manqué au moins une expédition cochée.

## Quand quelque chose vous bloque

| Vous voyez | Que faire |
| --- | --- |
| *Aucune expédition finalisée cette année* | Choisissez une autre année, ou finalisez d'abord les expéditions de l'année |
| Un modèle est signalé à l'étape 2 | Cliquez sur **Corriger les modèles**, corrigez-le dans le nouvel onglet, puis cliquez sur **Vérifier à nouveau** |
| Un avertissement jaune indique que beaucoup de laboratoires ont manqué une expédition | Les expéditions cochées ont été envoyées à des laboratoires différents. Cliquez sur **Changer** à l'étape 1 et cochez un seul groupe. Créez un deuxième lot pour l'autre groupe |
| La génération s'arrête sur une erreur | Lisez le message, corrigez la cause et cliquez sur **Recommencer** |
| Un certificat semble incorrect | Cliquez sur **Abandonner ce lot**, corrigez la cause et recommencez à l'étape 1 |

Les participants ne voient rien tant que vous n'avez pas approuvé le
lot.

**Lots précédents**, en haut de la page, liste les lots des années
précédentes.
