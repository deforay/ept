# Ajouter une technique / plateforme EID

Ce formulaire crée une nouvelle technique / plateforme EID dans l'une
des deux catégories : **Extraction** ou **Détection**. Les deux
catégories ont des listes séparées. Choisissez la bonne avant
d'enregistrer.

## Champs

- **Choisissez une catégorie** *(obligatoire)* : *Extraction* ou
  *Détection*. La catégorie est présélectionnée selon l'onglet d'où
  vous venez dans la liste des techniques EID. Elle détermine la liste
  dans laquelle la nouvelle entrée est ajoutée (et la liste où les
  doublons sont recherchés).
- **Nom** *(obligatoire)* : le nom de la technique / plateforme. Le
  formulaire recherche les doublons dans la catégorie choisie.

## Enregistrer

- **Ajouter** : enregistre et revient à la liste des techniques EID,
  filtrée sur la catégorie que vous venez d'ajouter.
- **Annuler** : abandonne les modifications et revient à la liste EID.

## Conseils

- **Choisissez d'abord la bonne catégorie.** Changer *Choisissez une
  catégorie* après avoir saisi un nom efface le champ. Définissez donc
  la catégorie en premier pour ne pas tout ressaisir.
- Une plateforme qui fait à la fois l'extraction et la détection doit
  être ajoutée **deux fois**, une fois par catégorie.
- Les nouvelles techniques sont **Actives** par défaut : elles
  apparaissent tout de suite dans la liste du participant. Utilisez le
  bouton de statut de la liste des techniques EID pour les désactiver
  plus tard si besoin.
- Il n'existe **pas de page de modification** pour les techniques EID.
  Une fois enregistré, le *Nom* ne peut plus changer. Vérifiez
  l'orthographe et les majuscules avant de cliquer sur *Ajouter*.
