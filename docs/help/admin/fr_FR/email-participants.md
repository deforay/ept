# Envoyer un e-mail aux participants

Rédigez un seul e-mail sur une ou plusieurs expéditions. Chaque
destinataire reçoit sa propre copie, avec les noms de ses propres
laboratoires.

La page comporte trois onglets : **Rédiger**, **Planifiés** et
**Historique**.

## Envoyer un rappel aux laboratoires qui n'ont pas répondu

1. Sous **Qui doit le recevoir**, sélectionnez les expéditions.
2. Sous **Envoyer à**, choisissez les destinataires de l'e-mail :
   **Participants**, **Gestionnaires de données** ou
   **Gestionnaires PTCC**.
3. Sous **Quels laboratoires**, choisissez **Uniquement les
   laboratoires qui n'ont pas répondu**.
4. Sous **Partir d'un modèle**, choisissez **Rappel de
   non-réponse**. L'objet et le message se remplissent.
5. Modifiez le message si nécessaire.
6. Cliquez sur **Aperçu**. Vérifiez la liste des destinataires et
   la copie que chacun reçoit.
7. Cliquez sur **Envoyer maintenant**, ou sur **Programmer…** pour
   l'envoyer plus tard.

Pour ouvrir cette page avec une expédition déjà sélectionnée,
cliquez sur **Relancer** dans la ligne de l'expédition, dans
**Gérer → Expéditions**. Le bouton **E-mail** d'une ligne d'enquête
PT fait de même pour toutes les expéditions de l'enquête.

## Choisir les destinataires

| Paramètre | Choix |
| --- | --- |
| **Envoyer à** | **Participants** (chaque laboratoire, à sa propre adresse), **Gestionnaires de données** (les personnes qui saisissent les résultats de ces laboratoires) ou **Gestionnaires PTCC** (coordinateurs nationaux, expéditions TB uniquement) |
| **Mettre aussi en Cc les gestionnaires de données de chaque laboratoire sur l'e-mail du laboratoire** | Affiché quand vous envoyez aux **Participants**. Met en copie les gestionnaires de données de chaque laboratoire |
| **Comment ils le reçoivent** | Affiché quand vous envoyez aux gestionnaires de données ou aux gestionnaires PTCC. **Un seul e-mail listant tous leurs laboratoires** (un par expédition) ou **Un e-mail par laboratoire** |
| **Quels laboratoires** | **Tous les laboratoires** ou **Uniquement les laboratoires qui n'ont pas répondu** |

Un e-mail va à un seul public. Après l'envoi ou la planification,
la page propose des boutons pour rédiger une version destinée à un
autre public, avec les mêmes expéditions et les mêmes laboratoires.

**Uniquement les laboratoires qui n'ont pas répondu** inclut les
laboratoires qui ont seulement enregistré un brouillon. Un e-mail
planifié vérifie de nouveau au moment de l'envoi. Les laboratoires
qui répondent avant ne le reçoivent donc pas.

## Rédiger le message

- **Partir d'un modèle** remplit l'objet et le message. Vous pouvez
  modifier les deux.
- Les **Champs de fusion** insèrent dans l'e-mail les valeurs propres
  à chaque destinataire, comme le nom du laboratoire, le code de
  l'expédition ou la date limite de réponse. Cliquez sur **Insérer un
  champ**, ou cliquez sur un champ de la liste **Champs de fusion**,
  pour l'insérer à la position du curseur.
- Le champ **Tableau des laboratoires** liste les laboratoires du
  destinataire et indique si chacun a répondu.

Les anciens modèles peuvent utiliser des champs au format `##NAME##`.
ePT les remplit toujours.

## Avant l'envoi

- **Aperçu** liste tous les destinataires et affiche chaque copie du
  message. Vous pouvez envoyer depuis l'aperçu.
- ePT ignore les adresses marquées comme rejetées ou invalides.
- La tâche d'envoi des e-mails envoie les messages en attente par
  lots. La livraison prend donc quelques minutes.

## Modifier ou arrêter un e-mail planifié

Ouvrez l'onglet **Planifiés**. Les heures sont affichées dans le
fuseau horaire indiqué en haut. Les destinataires sont déterminés au
moment de l'envoi.

| Bouton | Action |
| --- | --- |
| **Modifier** | Modifie l'e-mail avant son envoi |
| **Suspendre** | Met l'e-mail en attente. Les messages déjà envoyés restent envoyés |
| **Reprendre** | Reprend un e-mail suspendu |
| **Envoyer maintenant** | Envoie immédiatement un e-mail planifié ou suspendu |
| **Annuler** | Arrête l'e-mail. Les messages déjà envoyés ne peuvent pas être rappelés |

## Vérifier ce qui a été envoyé

Ouvrez l'onglet **Historique**. Il liste les 200 derniers e-mails
envoyés et annulés. Les nombres de livraisons sont conservés pendant
30 jours après l'envoi.
