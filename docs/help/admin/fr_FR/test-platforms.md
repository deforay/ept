# Plateformes de test

Une plateforme de test est un test ou un instrument avec lequel un
participant déclare un résultat SARS-CoV-2. Les participants
choisissent une plateforme pour chaque test dans leur formulaire de
réponse.

Ouvrez **Configurer → Configuration des programmes**. Dans le menu
latéral, ouvrez **SARS-CoV-2** et cliquez sur **Plateformes de test**.

## Ajouter une plateforme de test

1. Cliquez sur **Ajouter une nouvelle plateforme de test**.
2. Saisissez le **Nom de la plateforme de test**.
3. Facultatif : saisissez un **Nom abrégé de la plateforme de test**.
4. Saisissez l'**Agence d'approbation**.
5. Dans **Programme**, choisissez le programme.
6. Dans **Pays approuvé/validé**, choisissez **Oui** ou **Non**.
7. Facultatif : remplissez **Référence de la source**, **Fabricant de
   la plateforme de test** et **Commentaires**.
8. Cliquez sur **Ajouter**.

Une nouvelle plateforme est enregistrée comme approuvée.

## Proposer une plateforme pour le test 1, 2 ou 3

Pour chaque test, le formulaire de réponse du participant liste
uniquement les plateformes associées à ce test.

1. Sur la page des plateformes de test, cliquez sur **Correspondance
   des plateformes de test standard Covid-19**. Le bouton apparaît
   quand le programme SARS-CoV-2 est actif.
2. Dans **Choisir le numéro du test**, choisissez **Test 1**,
   **Test 2** ou **Test 3**.
3. Cliquez sur le nom d'une plateforme pour la déplacer d'une liste à
   l'autre. Utilisez **Tout sélectionner** et **Tout désélectionner**
   pour déplacer toutes les plateformes.
4. Cliquez sur **Enregistrer la sélection**.

La correspondance ne liste que les plateformes SARS-CoV-2 dont le
champ **Pays approuvé/validé** vaut **Oui**.

## La liste des plateformes

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Nom de la plateforme de test** | Le nom de la plateforme |
| **Nom du programme** | Le programme auquel la plateforme appartient |
| **Fabricant de la plateforme de test** | Le fabricant |
| **Agence d'approbation** | L'agence qui a approuvé la plateforme |
| **Approuvé** | **Oui** ou **Non** |
| **Créé le** | La date d'ajout de la plateforme |

Utilisez **Statut d’approbation** pour afficher toutes les
plateformes, les plateformes approuvées ou les plateformes non
approuvées.

## Modifier une plateforme de test

1. Cliquez sur **Edit** dans la ligne de la plateforme.
2. Modifiez les champs. **Approuvé** indique si la plateforme compte
   comme approuvée dans la liste.
3. Cliquez sur **Mettre à jour**.

La page n'a pas de bouton de suppression.
