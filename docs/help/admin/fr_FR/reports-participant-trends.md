# Tendances des participants

**Rapports → Tendances des participants** montre comment les participants répondent et quels sont leurs résultats d'une expédition à l'autre. Le titre de la page est **Aperçu des performances des participants**.

La page s'ouvre sur un aperçu de tous les programmes pour les trois dernières années. Cliquez sur la ligne d'un programme pour voir ses expéditions une par une.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres. Réglez-les, puis cliquez sur **Obtenir un rapport**.

| Filtre | Effet | Valeur par défaut |
|---|---|---|
| Plage de dates | Inclut les expéditions dont la date d'expédition se trouve dans cette période. | 3 dernières années |
| Programme | Le programme sur lequel porte le rapport. Laissez ce champ vide pour l'aperçu de tous les programmes. | Vide. Si un seul programme est actif, ce programme. |
| Expédition | Limite le rapport à une seule expédition. | Toutes les expéditions de la période |

Chaque filtre actif s'affiche sous forme d'étiquette à côté du bouton **Afficher les filtres**.

- Cliquez sur une étiquette pour ouvrir le panneau des filtres sur ce filtre.
- Cliquez sur **×** sur une étiquette pour retirer ce filtre.

## Encadrés de synthèse

Les quatre encadrés additionnent toutes les expéditions du rapport.

| Encadré | Contenu |
|---|---|
| Inscrits | Le nombre de participants inscrits et le nombre d'expéditions. |
| Taux de réponse | Le pourcentage de participants inscrits qui ont répondu. |
| Dans les délais | Le pourcentage de réponses soumises avant la date limite. |
| Taux de réussite | Le pourcentage de réponses évaluées qui ont réussi. Affiche **Pas encore évalué** avant l'évaluation. |

## Tendance par envoi

Le graphique montre le taux de réponse, le taux de réponses dans les délais et le taux de réussite de chaque expédition, dans l'ordre des dates d'expédition. Pointez une expédition pour voir ses trois valeurs.

Le graphique ne s'affiche que si le rapport contient au moins deux expéditions.

## Tableau des expéditions

Chaque ligne correspond à une expédition.

| Colonne | Contenu |
|---|---|
| Expédition | Le code de l'expédition et la date d'expédition. |
| Inscrits | Le nombre de participants inscrits. |
| Répondu | Le nombre de participants qui ont répondu et le taux de réponse. |
| Dans les délais | Le pourcentage de réponses soumises avant la date limite. |
| Taux de réussite | Le pourcentage de réponses évaluées qui ont réussi, avec une barre. |
| Appréciations | Une barre divisée selon les trois appréciations ci-dessous. Pointez la barre pour voir les chiffres. |

Une expédition qui n'est pas encore évaluée affiche **Pas encore évalué** à la place du taux de réussite et des appréciations.

| Appréciation | Signification |
|---|---|
| Excellent | Réussi avec le score maximal. |
| Satisfaisant | Réussi avec un score inférieur au maximum. |
| Insatisfaisant | Échec. |

Cliquez sur une expédition pour afficher ses régions sous la ligne. Chaque région affiche les mêmes colonnes que l'expédition. Les participants sans région sont regroupés sous **Sans région**, à la fin. Cliquez de nouveau sur l'expédition pour masquer ses régions.

## Mode de comptage des participants

| Terme | Signification |
|---|---|
| Inscrits | Tous les participants inscrits à l'expédition. |
| Répondu | A soumis des résultats, y compris en retard, ou a indiqué ne pas avoir pu tester. |
| Dans les délais | A répondu, et la réponse n'était pas en retard. |
| Évalué | Réussi ou échec. Les participants qui n'ont pas répondu ne sont jamais comptés en échec. |

## Télécharger Excel

**Télécharger Excel** enregistre le rapport dans un fichier Excel avec deux feuilles.

| Feuille | Contenu |
|---|---|
| Expéditions | Une ligne par expédition, avec tous les totaux et pourcentages du tableau. |
| Régions | Une ligne par région de chaque expédition. |

Le fichier utilise les filtres du rapport affiché à l'écran.
