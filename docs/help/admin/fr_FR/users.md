# Responsables PT

Gérez les comptes administrateurs dans **Configurer → Responsables PT**.
Cette page nécessite le privilège de configuration.

Les responsables PT utilisent l'espace d'administration.
Les gestionnaires de données utilisent le portail participant pour les participants associés à leur compte.
Une fiche participant est distincte de ces deux types de compte.

## Ajouter un compte

1. Sélectionnez **Ajouter** dans la page Responsables PT.
2. Saisissez le nom, le courriel principal, le mot de passe initial et les coordonnées obligatoires.
3. Sélectionnez les programmes actifs attribués au compte.
4. Sélectionnez les privilèges approuvés.
5. Définissez le statut du compte, puis soumettez le formulaire.
6. Organisez la transmission sécurisée des identifiants initiaux.
7. Confirmez que le titulaire peut se connecter et changer son mot de passe initial.

Le formulaire utilise des attributions de programmes et des privilèges individuels.
Il ne propose pas de liste fixe de rôles Super Admin, Relecteur et Lecture seule.
La création d'un compte nécessite un mot de passe initial.
Ne supposez pas qu'elle envoie un lien d'invitation.

## Modifier un accès

1. Sélectionnez **Modifier** pour le responsable PT.
2. Modifiez le statut, les programmes attribués ou les privilèges selon la demande approuvée.
3. Soumettez le formulaire.
4. Vérifiez les accès après une nouvelle connexion.

Pour désactiver un compte, définissez son statut sur **Inactif**.
Vérifiez le rejet d'une nouvelle connexion. Conservez la fiche du compte pour attribuer les actions historiques.

## Rétablir un accès

Utilisez la récupération de mot de passe de l'écran de connexion ou contactez l'opérateur technique autorisé.
L'opérateur dispose d'outils CLI distincts pour réinitialiser les mots de passe des administrateurs et des gestionnaires de données.
Confirmez le type de compte avant de demander une réinitialisation.

## Vérifier une attribution

Confirmez que le compte peut accomplir la tâche attribuée pour le programme prévu.
Confirmez aussi le rejet d'une opération administrative non autorisée.
Consignez le relecteur et la date dans le registre local de revue des accès.
