# Gérer l'inscription

Vous êtes sur cette page parce que vous avez cliqué sur **Enrollment**
pour une expédition déjà expédiée. Avant l'expédition, la ligne affiche
**Inscrire** à la place. Ce bouton ouvre le sélecteur de participants.

Le haut de la page affiche le code de l'expédition, le programme,
l'enquête PT et la **Date limite de soumission des résultats**.

## Les trois onglets

| Onglet | Ce qu'il liste |
| --- | --- |
| **Répondu** | Les participants inscrits qui ont envoyé une réponse |
| **Pas de réponse** | Les participants inscrits qui n'ont pas encore répondu |
| **Non inscrit à cette expédition** | Les participants actifs qui ne sont pas dans cette expédition |

Cliquez sur **Exporter vers Excel** pour enregistrer l'onglet ouvert
dans un fichier.

## Ajouter un participant après l'expédition

1. Ouvrez l'onglet **Non inscrit à cette expédition**.
2. Trouvez le participant. Utilisez les champs de recherche pour réduire
   la liste.
3. Cliquez sur **Inscrire** sur sa ligne. Pour en ajouter plusieurs,
   sélectionnez-les et cliquez sur **Inscrire** en bas de la page.
4. Confirmez. Le participant voit maintenant l'expédition et peut
   répondre.

## Retirer un participant

Cliquez sur **Supprimer** sur la ligne du participant, puis confirmez.
Cette action est irréversible. Si l'expédition était déjà évaluée,
évaluez-la de nouveau pour que les totaux soient justes.

## Copier les adresses e-mail

Les boutons **Copy Emails** copient des adresses dans le presse-papiers.
Vous pouvez ensuite les coller dans votre propre messagerie :

- **Copier les e-mails : inscrits** : les participants et les
  gestionnaires de données de cette expédition.
- **Copier les e-mails : sans réponse** : ceux qui n'ont pas répondu.
- **Copier les e-mails : non inscrits** : les participants actifs qui ne
  sont pas dans cette expédition.
- **Copier les e-mails : PTCC** : les coordinateurs nationaux des
  participants inscrits.

Pour envoyer plutôt une relance depuis ePT, utilisez **Relancer** sur la
ligne de l'expédition. Voir
[Envoyer un e-mail aux participants](email-participants.md).
