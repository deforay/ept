# Mon profil

Cette page contient les informations de votre propre compte
administrateur. Tout administrateur peut l'ouvrir.

Cliquez sur votre prénom en haut à droite de la page, puis sur **Mon
profil**.

## Modifier vos informations

1. Dans **Informations personnelles**, modifiez les champs voulus :

   | Champ | Usage |
   | --- | --- |
   | **Prénom** | Votre prénom. Obligatoire |
   | **Nom** | Votre nom de famille. Obligatoire |
   | **Adresse e-mail principale** | L'adresse avec laquelle vous vous connectez |
   | **E-mail secondaire** | Une deuxième adresse |
   | **Téléphone** | Votre numéro de téléphone, avec l'indicatif du pays |
   | **Langue** | La langue des pages d'administration |

2. Cliquez sur **Mettre à jour le profil**.

Le tableau de bord s'ouvre et affiche *Profile updated successfully.*

Si vous modifiez l'**Adresse e-mail principale**, connectez-vous
ensuite avec la nouvelle adresse.

Les pages d'administration passent à la nouvelle **Langue** après
l'enregistrement.

## Modifier votre mot de passe

1. Dans **Modifier le mot de passe**, saisissez votre **Mot de passe
   actuel**.
2. Saisissez le **Nouveau mot de passe**. Il doit compter au moins
   8 caractères, avec une lettre, un chiffre et un symbole.
3. Saisissez-le de nouveau dans **Confirmer le nouveau mot de passe**.
   L'indication sous le champ montre si les deux correspondent.
4. Cliquez sur **Mettre à jour le profil**.

Pour garder votre mot de passe actuel, laissez les champs de mot de
passe vides.

Pour quitter la page sans enregistrer, cliquez sur **Retour**.
