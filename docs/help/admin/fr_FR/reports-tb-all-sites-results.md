# TB : Résultats de tous les sites

**Rapports → TB : Résultats de tous les sites** crée un classeur Excel pour une expédition TB. Le classeur contient une ligne par participant, avec le résultat de chaque échantillon.

## Générer un classeur

1. Choisissez l'expédition dans **Expédition**. La liste contient toutes les expéditions TB non annulées, les plus récentes en premier.
2. Cliquez sur **Générer le classeur**.
3. Cliquez sur **Télécharger** à côté du classeur.

Chaque classeur créé reste dans la liste **Classeurs** jusqu'à ce que vous quittiez la page.

## Colonnes de soumission et de résultat

Le classeur est en anglais. Les colonnes et les valeurs ci-dessous gardent donc leur nom anglais.

| Colonne | Valeurs |
|---|---|
| Submitted | **Yes**, **Yes (Late)**, **Yes (Not Tested)** ou **No**. |
| Satisfactory/Unsatisfactory | **Satisfactory**, **Unsatisfactory**, **Excluded**, **Not Tested**, **Not Submitted** ou **Not Evaluated**. |

Seule une réponse évaluée et en échec affiche **Unsatisfactory**.
