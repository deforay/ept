# Tableau de bord

Le tableau de bord affiche les cycles PT que vous gérez et l'étape
suivante pour chacun. Commencez ici après vous être connecté.

## Trouver le cycle sur lequel vous travaillez

Le tableau des cycles liste chaque cycle ouvert aux réponses ou en
attente de finalisation. Chaque ligne indique la **Date limite**, le
nombre de laboratoires qui ont **Répondu**, le **% de réponses** et le
**% de réussite**.

Le bouton **Action suivante** vous indique quoi faire :

| Action suivante | Signification |
| --- | --- |
| **En attente de réponses** | Le cycle est ouvert. Cliquez pour voir les laboratoires qui n'ont pas répondu |
| **Aucune réponse reçue** | La date limite est passée et aucun laboratoire n'a répondu |
| **Prêt à évaluer** | Les réponses sont arrivées. Cliquez pour évaluer l'expédition |
| **Générer les rapports** | L'expédition est évaluée. Cliquez pour générer les rapports |
| **Prêt à finaliser** | Les rapports sont générés. Cliquez pour vérifier et finaliser |

Cliquez sur **en attente** dans une ligne pour voir les laboratoires
qui doivent encore répondre.

## Les cartes du haut

- **Participants actifs** : les laboratoires inscrits à vos programmes.
- **Cycles en cours** : les cycles ouverts aux réponses et les cycles
  en attente de finalisation.
- **Laboratoires n'ayant pas encore répondu** : les laboratoires des
  cycles ouverts qui n'ont pas répondu.
- **Cycles terminés en** : les cycles finalisés cette année.

Un avis au-dessus des cartes signale les participants qui se sont
inscrits et attendent une approbation. Cliquez dessus pour les examiner.

## Cycles précédents

Sous le tableau, **Cycles précédents** affiche les cycles finalisés
avec leur **Participation** et leurs **Résultats**. **Échecs répétés**
compte les laboratoires qui ont échoué à ce cycle et au cycle
précédent. **Jamais de réponse** compte les laboratoires qui ont
manqué chacun des derniers cycles finalisés du programme. Ces deux
indicateurs nécessitent un cycle finalisé antérieur du même programme.

## Engagement des participants

**Participation par programme** indique combien de laboratoires de
chaque programme sont en **Participation active**, et combien sont
**Inscrits à un programme, sans réponse**. Un laboratoire est compté
comme participant dès qu'il répond à un cycle expédié au cours des
derniers mois.

## Conseils

- Les chiffres se mettent à jour à chaque ouverture de la page.
  Rechargez-la pour voir une modification que vous venez de faire.
- Appuyez sur **Ctrl + K** pour rechercher une page par son nom.
