# Paramètres EID

Cette page définit comment les expéditions de diagnostic précoce du
nourrisson (EID) sont notées.

## Champs

Le **Score de réussite** est le score minimal qu'un participant doit
obtenir pour réussir une expédition EID. Saisissez un nombre entier de
1 à 100. Laissez le champ vide pour utiliser la valeur par défaut de
100.

Cliquez sur **Mettre à jour** pour enregistrer.

## Après la modification du score

Le nouveau score s'applique à la prochaine évaluation d'une expédition.
Pour mettre à jour une expédition déjà évaluée, évaluez-la de nouveau
dans **Analyse → Évaluer les réponses**.
