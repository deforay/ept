# Modifier une liste d'inscription

Le titre indique le programme et la liste. La page comporte deux
listes :

- **Pas sur cette liste** (à gauche) : les participants actifs qui
  ne sont pas sur cette liste.
- **Sur cette liste** (à droite) : les participants actifs inscrits
  sur cette liste.

Cliquez sur un participant pour le déplacer vers l'autre liste.
Chaque ligne affiche l'ID du laboratoire et le nom. Saisissez du
texte dans la zone de recherche d'une liste pour trouver un
participant par nom ou par ID du laboratoire.

- **Ajouter tous ceux affichés** : déplace vers la droite tous les
  participants affichés par la recherche de gauche.
- **Retirer tous ceux affichés** : déplace vers la gauche tous les
  participants affichés par la recherche de droite.

## Filtres

**Pays**, **Province** et **District** restreignent la liste de
gauche. Cliquez sur **Plus de filtres** pour afficher
**Établissement**, **Niveau du réseau** et **Affiliation**. Les
participants déjà sur la liste restent toujours à droite. Changer un
filtre conserve les modifications non enregistrées.

## Couleurs

| Marque | Signification |
| --- | --- |
| Coche grise | Sur la liste et enregistré |
| **+** vert | Sera ajouté à l'enregistrement |
| **−** orange | Sera retiré à l'enregistrement |

Les lignes non enregistrées apparaissent en premier.

## Enregistrer

La barre en bas indique combien de participants seront ajoutés et
retirés.

- **Enregistrer les modifications** : enregistre la liste exactement
  comme l'affiche le côté droit. Les participants déplacés à gauche
  sont retirés de cette liste.
- **Abandonner** : supprime vos modifications non enregistrées.

Si vous quittez la page avec des modifications non enregistrées, la
page vous le demande d'abord. L'enregistrement d'une liste vide
demande une confirmation.

Retirer un participant de cette liste ne le retire pas des autres
listes du programme. Les participants inactifs ne sont pas affichés.
L'enregistrement les conserve sur la liste.

## Renommer

Cliquez sur **Renommer** en haut pour changer le nom de la liste. La
liste Default ne peut pas être renommée. Enregistrez ou abandonnez
d'abord vos modifications.
