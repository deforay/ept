# Rapport sur les actions correctives

**Rapports → Rapport sur les actions correctives** indique combien de fois chaque action corrective a été attribuée aux réponses DTS. L'évaluation attribue une action corrective quand une réponse ne respecte pas une règle. Par exemple, l'approbation du superviseur manque ou le kit de test est expiré.

Le rapport s'affiche dès l'ouverture de la page. Les filtres s'appliquent dès que vous les modifiez. Il n'y a pas de bouton **Obtenir un rapport**.

## Réponses prises en compte

Le rapport compte les réponses DTS soumises et non exclues. Les réponses soumises en retard sont comptées. Les participants qui n'ont pas répondu ne sont jamais comptés, même si une ancienne évaluation leur a attribué des actions correctives.

Les expéditions annulées n'apparaissent jamais dans ce rapport.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres. Le rapport ne couvre que le DTS. Il n'y a donc pas de filtre par programme. Si le DTS n'est pas actif, la page l'indique.

| Filtre | Effet | Valeur par défaut |
|---|---|---|
| Date d'expédition | Inclut les expéditions dont la date d'expédition se trouve dans cette période. Cliquez sur **Effacer** dans le sélecteur de dates pour inclure toutes les dates. | 3 dernières années |
| Expédition | Inclut uniquement les expéditions choisies. Vous pouvez en choisir plusieurs. La liste contient toutes les expéditions DTS non annulées de la période. | Toutes les expéditions de la période |
| Pays, Région, Province, District | Inclut uniquement les participants de ce lieu. Chaque filtre ne s'affiche que si ce champ est renseigné pour des participants. | Tous |

Chaque filtre actif s'affiche sous forme d'étiquette à côté du bouton **Afficher les filtres**.

- Cliquez sur une étiquette pour ouvrir le panneau des filtres sur ce filtre.
- Cliquez sur **×** sur une étiquette pour retirer ce filtre.

## Totaux

Les quatre encadrés au-dessus du tableau comptent les réponses qui correspondent aux filtres.

| Encadré | Contenu |
|---|---|
| Expéditions | Le nombre d'expéditions. |
| Réponses | Le nombre de réponses. En dessous, le nombre de réponses en échec. |
| Avec une mesure corrective | Le nombre de réponses qui ont reçu au moins une action corrective. En dessous, leur part dans l'ensemble des réponses. |
| Score moyen | Le score moyen des réponses évaluées. |

## Actions correctives

Chaque ligne correspond à une action corrective. Les actions correctives les plus fréquentes apparaissent en premier.

| Colonne | Contenu |
|---|---|
| Action corrective | Le texte de l'action corrective. |
| Réponses | Le nombre de réponses qui ont reçu l'action corrective, avec une barre. En dessous, leur part dans l'ensemble des réponses. |
| Participants | Le nombre de participants qui ont reçu l'action corrective. |
| Échec | Le nombre de ces réponses en échec. |

Cliquez sur une action corrective pour afficher, sous la ligne, la liste des réponses qui l'ont reçue. La liste indique le participant, le lieu, l'expédition, le score et le résultat. Elle affiche les 100 réponses les plus récentes. **Télécharger Excel** fournit la liste complète. Cliquez de nouveau sur l'action corrective pour masquer la liste.
