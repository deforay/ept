# Modifier une enquête PT

Utilisez ce formulaire pour changer le **Code de l'enquête PT** ou la
**Date de l'enquête PT** après la création de l'enquête. Les champs
sont les mêmes que dans *Ajouter une enquête PT*. Consultez cette page
pour la signification de chaque champ.

## Différences avec l'ajout

- Le **Code de l'enquête PT** est modifiable. La recherche de doublons
  ignore l'enquête *en cours*, vous pouvez donc corriger une faute de
  frappe sans que le formulaire la refuse.
- La **Date de l'enquête PT** est aussi modifiable. Un cercle rouge
  signale les dates qui ont une autre enquête. Vous pouvez quand même
  en choisir une, et la page vous avertit du conflit.
- Le titre en haut indique **Modifier l'enquête PT**, pour montrer
  clairement que vous travaillez sur une fiche existante.

## Enregistrer : deux options

- **Mettre à jour** *(principal)* : enregistre vos modifications et
  revient à la liste des enquêtes.
- **Ajouter et passer à l'expédition** : enregistre vos modifications
  et ouvre la page des expéditions. Utile quand l'enquête est encore à
  l'état **Créé** et qu'il faut ajouter ou ajuster des
  expéditions.

Utilisez **Annuler** pour abandonner les modifications et revenir à
la liste des enquêtes.

## Modifier après l'expédition

Une fois l'enquête expédiée (statut **Already shipped**), elle est
déjà visible pour les participants. Le système protège les enquêtes
expédiées contre les modifications qui pourraient les dérouter :

- La date reste modifiable. Réfléchissez avant de la changer, car
  les participants l'ont déjà vue.
- Le Code de l'enquête PT reste modifiable jusqu'à la finalisation
  d'une des expéditions de l'enquête. Il est ensuite verrouillé, car
  les rapports finalisés l'impriment. Les participants ont aussi vu
  l'ancien code dans leurs e-mails et leurs tableaux de bord.

Pour des modifications plus importantes sur une enquête expédiée,
ajustez les *expéditions* concernées depuis la page des expéditions
plutôt que l'enquête elle-même.

## Conseils

- Modifier la date réordonne la liste des enquêtes (elle est triée
  par date). Une enquête modifiée peut apparaître à une autre place
  quand vous revenez.
- La recherche de codes en double se lance dès que vous quittez le
  champ. Vous voyez donc l'erreur avant d'envoyer le formulaire.
