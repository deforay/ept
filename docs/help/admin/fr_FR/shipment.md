# Expéditions

Une **expédition** est un ensemble d'échantillons de test que vous
envoyez aux participants dans le cadre d'une enquête PT. Une enquête PT
peut contenir une ou plusieurs expéditions.

Une expédition comprend :

- Un **programme** (le type de test, comme la sérologie VIH ou la CV).
- Une liste d'**échantillons** avec leurs résultats attendus.
- Les **participants** que vous voulez inscrire à cette expédition.

Vous ajoutez toujours les expéditions dans une enquête PT. Les étapes
sont donc :

1. Créez d'abord l'enquête PT (date et code).
2. Ajoutez-y ensuite une ou plusieurs expéditions.
3. Inscrivez ensuite des participants à chaque expédition.
4. Cliquez enfin sur **Expédier maintenant** dans la page de l'enquête PT.

## Le contenu de la page

Cette page affiche toutes les expéditions de votre système. Vous pouvez :

- **Rechercher** par code d'expédition, programme ou enquête PT.
- **Trier** en cliquant sur les en-têtes de colonnes.
- Utiliser les boutons de chaque ligne. Les boutons affichés dépendent
  du statut de l'expédition.

| Bouton | Quand il apparaît | Ce qu'il fait |
| --- | --- | --- |
| **Modifier** | Jusqu'à la finalisation de l'expédition | Modifie les échantillons, la date limite et d'autres détails |
| **Dupliquer** | Toujours | Crée une nouvelle expédition avec les mêmes échantillons et paramètres |
| **Inscrire** | Avant l'expédition | Choisit les participants qui reçoivent l'expédition. En rouge : aucun participant pour l'instant |
| **Inscriptions** | Après l'expédition | Montre qui a répondu et permet d'ajouter des participants non inscrits |
| **Relancer** | Après l'expédition, tant que des laboratoires n'ont pas répondu | Ouvre Envoyer un e-mail aux participants pour cette expédition |
| **Configurer le formulaire de feedback** | L'expédition recueille du feedback mais n'a pas de formulaire | Crée le formulaire. L'expédition ne peut pas être finalisée sans lui |
| **Annuler** | Jusqu'à la finalisation de l'expédition | Annule l'expédition. Vous indiquez un motif. Cette action est irréversible |

## Les tâches courantes sur cette page

- **Ajouter une nouvelle expédition** : choisissez le type de test dans
  **Type de programme** en haut de cette page, puis cliquez sur
  **Nouvelle expédition**. Ou bien allez dans **Gérer → Enquête PT** et cliquez
  sur **Ajouter une expédition** à côté de votre enquête. Cette page
  s'ouvre alors pour cette enquête.
- **Ajouter ou retirer des participants** : trouvez votre expédition,
  cliquez sur **Inscrire**, cliquez sur les noms pour les déplacer d'un
  côté à l'autre, puis cliquez sur **Inscrire** pour enregistrer.
- **Modifier les échantillons ou la date limite de soumission des
  résultats** : cliquez sur **Modifier** pour l'expédition, modifiez les
  champs, puis enregistrez.

## Quand une expédition devient visible pour les participants

Les expéditions ne sont **pas** visibles pour les participants dès leur
création. Les participants voient une expédition seulement après que vous
avez cliqué sur **Expédier maintenant** dans son enquête PT. Jusque-là,
vous pouvez modifier sans risque les échantillons, les inscriptions et la
date limite.

## Conseils

- Une enquête PT **sans expédition** ne peut pas être expédiée. Le bouton
  **Expédier maintenant** n'apparaît pas.
- Les participants inscrits au **programme** (Configurer → Inscriptions
  au programme) sont sélectionnés par défaut quand vous cliquez sur
  **Inscrire**. Vous pouvez ajouter d'autres participants actifs sur la
  même page.
- Après l'expédition, évitez de modifier les échantillons ou les
  inscriptions. Les participants ont peut-être déjà commencé à saisir
  des résultats.
