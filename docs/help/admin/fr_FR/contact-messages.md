# Messages de contact

Cette page liste les messages envoyés depuis le formulaire de
contact de la page d'accueil, du plus récent au plus ancien. ePT
enregistre chaque message ici, même quand il ne peut pas envoyer
d'e-mail.

## Lire un message et y répondre

1. Ouvrez **Configurer → Messages de contact**.
2. Trouvez le message. Saisissez un nom, une adresse e-mail, un
   code de participant ou un mot du message dans la zone de
   recherche.
3. Lisez l'**Objet** et le **Message**.
4. Écrivez à l'expéditeur depuis votre propre compte de
   messagerie, à l'adresse indiquée sous **De**.

ePT envoie aussi chaque message par e-mail à l'**E-mail de
l'administrateur** défini dans **Configurer → Paramètres globaux
d'ePT**. Répondez à cet e-mail pour répondre à l'expéditeur. Si un
PTCC connecté envoie le message, il en reçoit aussi une copie.

## Quand l'e-mail ne fonctionne pas

Si ePT ne peut pas envoyer d'e-mail, les messages de contact ne
parviennent à personne par e-mail. La barre du **Tableau de bord**
indique alors combien de messages sont arrivés sans que personne
n'en soit averti par e-mail. Cliquez sur **Ouvrir les messages de
contact** dans cette barre pour les lire ici.

## Colonnes

| Colonne | Contenu |
| --- | --- |
| **Reçu le** | La date d'arrivée du message et l'adresse IP de l'expéditeur |
| **De** | Le nom, l'adresse e-mail et le **Code/ID du participant** de l'expéditeur |
| **Pays** | Le pays choisi par l'expéditeur |
| **Objet** | L'objet saisi par l'expéditeur |
| **Message** | Le texte du message |
| **Action** | **Créer un identifiant de gestionnaire de données** |

Les adresses web d'un message s'affichent en texte simple, par
exemple `hxxps://example[.]com`. Un clic ne peut pas les ouvrir.

## Ajouter un identifiant pour l'expéditeur

Cliquez sur **Créer un identifiant de gestionnaire de données** pour
ouvrir **Ajouter un nouveau gestionnaire de données (identifiant du
participant)**. L'e-mail, le nom, le laboratoire et le téléphone de
l'expéditeur sont déjà remplis. Complétez le
formulaire et enregistrez-le. Voir [Formulaire du gestionnaire de
données](data-managers-form.md).
