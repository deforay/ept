# Fichiers pour les participants

Cette page envoie des fichiers aux participants que vous choisissez.
Chaque participant trouve les fichiers dans **Téléchargements**, dans son
compte. ePT n'envoie pas les fichiers par e-mail.

La page comporte trois étapes. Rien n'est envoyé tant que vous ne
cliquez pas sur **Distribuer les fichiers** à la dernière étape.

## Étape 1 : Choisir les participants

1. Réduisez la liste avec les filtres : **Type de programme**,
   **Expédition**, **Pays**, **Région**, **Province**, **District** et
   **Résultat**.
2. Cliquez sur **Charger les participants**.
3. Décochez tout participant qui ne doit pas recevoir les fichiers.
   Utilisez le champ de recherche pour en trouver un.
4. Cliquez sur **Suivante**.

## Étape 2 : Téléverser les fichiers

Déposez les fichiers sur la page, ou cliquez pour les parcourir. La page
liste les types de fichiers qu'elle accepte. Elle refuse les autres
types et nomme les fichiers qu'elle n'a pas acceptés.

Cliquez sur **Suivante**.

## Étape 3 : Confirmer et envoyer

1. Vérifiez les fichiers et le nombre de destinataires.
2. Retirez tout fichier téléversé par erreur, ou cliquez sur
   **Précédent** pour en ajouter d'autres.
3. Cliquez sur **Distribuer les fichiers**.

## Problèmes courants

| Message | Que faire |
| --- | --- |
| *Aucun participant ne correspond aux filtres sélectionnés* | Élargissez les filtres et cliquez de nouveau sur **Charger les participants** |
| *Veuillez sélectionner au moins un participant* | Cochez au moins un participant à l'étape 1 |
| *Veuillez téléverser au moins un fichier* | Téléversez un fichier à l'étape 2 |
| *Ces fichiers n'ont pas été acceptés (type de fichier non pris en charge)* | Enregistrez le fichier dans un type accepté et téléversez-le de nouveau |
