# Coordinateurs PT nationaux (PTCC)

Cette page liste les **coordinateurs PT nationaux** (PT Country
Coordinators, PTCC). Le programme TB utilise ce rôle. Un PTCC
couvre une région (pays, État ou district). Il voit les
participants de cette région.

## Boutons en haut de la page

- **Ajouter un nouveau PTCC** : ouvre le formulaire pour ajouter
  un PTCC.
- **Importation groupée des PTCC** : charge de nombreux PTCC à
  partir d'un tableur.
- Menu **Réinitialiser le mot de passe** :
  - **Réinitialiser à partir de la liste collée** : ouvre une
    fenêtre où vous collez des adresses e-mail ou des ID du
    laboratoire. Seuls les comptes PTCC correspondent. Vous mettez
    ensuite en file d'attente une réinitialisation du mot de passe
    et vous pouvez envoyer à chaque PTCC ses nouveaux identifiants
    par e-mail.
  - **PTCC actifs + mots de passe** : définit un nouveau mot de
    passe pour **chaque PTCC actif** et télécharge la liste avec
    les nouveaux mots de passe. Les anciens mots de passe cessent
    de fonctionner immédiatement. Vous devez saisir une
    confirmation avant le lancement. Cette action est
    irréversible.
- Menu **Exporter** :
  - **PTCC** : télécharge la liste complète des PTCC dans Excel.
  - **Participants associés au PTCC** : télécharge chaque PTCC
    avec les participants de sa région.
  - **E-mails inutilisables** : télécharge une liste Excel des
    comptes dont l'adresse e-mail manque, a été rejetée ou ne peut
    pas recevoir de messages.

## Filtres

- **Statut** *(par défaut : Actif)* : *Actif*, *Inactif* ou
  *Tout*. Actif est la valeur par défaut, pour que les
  coordinateurs qui ne sont plus en poste ne gênent pas.
- **Zones de recherche sous chaque titre de colonne** : chaque
  zone cherche uniquement dans sa colonne.

## Colonnes

- **Prénom**, **Nom**, **Cellulaire/mobile**, **Adresse e-mail
  principale**, **Statut**
- **Pays**, **État**, **District** : la région couverte par le
  PTCC.
- **Participants associés** : un bouton **Voir (n)**. Cliquez
  dessus pour lister les participants de la région de ce PTCC.
  Cliquez de nouveau pour fermer.
- **Action** : voir ci-dessous.

## Colonne Action

Chaque ligne contient ces boutons :

- **Modifier** : ouvre le formulaire de modification. Changez la
  région ici.
- **Mot de passe** : ouvre une fenêtre pour définir un nouveau mot
  de passe pour ce PTCC.
- **E-mail** : ouvre une fenêtre pour changer l'**Adresse e-mail
  principale**. L'adresse e-mail principale sert aussi
  d'identifiant.
- **Voir comme** : ouvre l'espace participant sous l'identité de
  ce PTCC, dans un nouvel onglet. Le bouton s'affiche seulement
  pour les PTCC actifs, et seulement pour les administrateurs qui
  ont cette autorisation. Chaque utilisation est enregistrée.

## Réinitialiser plusieurs mots de passe à la fois

1. Cochez la case au début de chaque ligne voulue. La case de
   l'en-tête coche toutes les lignes de la page affichée.
2. Cliquez sur **Mettre en file d'attente la réinitialisation et
   l'e-mail**.

Les réinitialisations s'exécutent en arrière-plan. Chaque PTCC
reçoit un e-mail avec ses nouveaux identifiants. Tant que des
lignes sont cochées, le menu **Réinitialiser le mot de passe**
masque **Réinitialiser à partir de la liste collée**.

## Conseils

- **Mot de passe et E-mail sont deux fenêtres différentes.** Si un
  PTCC n'a plus accès à son ancienne adresse e-mail, changez
  d'abord l'adresse e-mail. La nouvelle adresse devient son
  identifiant. Réinitialisez ensuite le mot de passe, pour que les
  nouveaux identifiants arrivent à la nouvelle adresse.
- **Participants associés au PTCC** permet de vérifier rapidement
  quels participants dépendent de chaque PTCC. C'est utile quand
  vous réorganisez les régions.
- Pour de nombreux nouveaux coordinateurs, utilisez **Importation
  groupée des PTCC**. Pour un ou deux, **Ajouter un nouveau PTCC**
  est plus rapide.
