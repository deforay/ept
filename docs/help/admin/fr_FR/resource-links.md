# Liens vers les ressources

La page d'accueil publique comporte trois sections ressources. Cette
page définit les liens et les fichiers listés dans chaque section.

Ouvrez **Configurer → Réglages de la page d’accueil**. Ouvrez
**Sections ressources** et cliquez sur **Gérer les liens vers les
ressources**.

## Ajouter un lien vers une ressource

1. Cliquez sur **Ajouter un nouveau lien vers une ressource**.
2. Dans **Section Ressources**, choisissez la section. **Ordre
   d'affichage** se remplit avec la prochaine position libre dans
   cette section.
3. Dans **Type**, choisissez **Lien** ou **Fichier**.
4. Si vous avez choisi **Lien**, saisissez l'adresse dans **Lien**.
5. Si vous avez choisi **Fichier**, choisissez le fichier dans
   **Fichier**.
6. Saisissez le **Texte affiché** que les visiteurs voient.
7. Dans **Icône**, choisissez **Document**, **Télécharger**, **Lien
   externe**, **Image** ou **Vidéo**.
8. Facultatif : modifiez l'**Ordre d'affichage**.
9. Dans **Statut**, choisissez **Actif**.
10. Cliquez sur **Ajouter**.

Un fichier doit être au format JPG, JPEG, PNG, PDF, DOC, DOCX, XLS ou
XLSX.

## La liste des liens

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Section Ressources** | La section sous laquelle le lien apparaît |
| **Lien** | L'adresse ou le fichier |
| **Texte affiché** | Le texte que les visiteurs voient |
| **Icône** | L'icône à côté du texte |
| **Ordre d'affichage** | La position dans la section |
| **Statut** | **Actif** ou **Inactif** |

La page d'accueil n'affiche que les liens actifs, dans l'**Ordre
d'affichage**.

## Modifier ou masquer un lien

1. Cliquez sur **Edit** dans la ligne du lien.
2. Modifiez les champs. Pour remplacer un fichier, choisissez-en un
   nouveau. Pour garder le fichier actuel, laissez **Fichier** vide.
3. Cliquez sur **Mettre à jour**.

Pour masquer un lien de la page d'accueil, réglez son **Statut** sur
**Inactif**.

Pour modifier les titres et les icônes des sections, voir
[Réglages de la page d’accueil](home-config.md).
