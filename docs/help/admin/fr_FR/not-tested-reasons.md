# Motifs de non-test

Quand un participant n'a pas pu tester une expédition, il choisit un
motif dans le formulaire de réponse. Cette page définit les motifs
qu'il peut choisir et les programmes qui proposent chaque motif.

Ouvrez **Configurer → Configuration des programmes**. Dans le menu
latéral, ouvrez **Partagé** et cliquez sur **Motifs de non-test**.

## Ajouter un motif

1. Cliquez sur **Ajouter un nouveau motif de non-réalisation du
   test**.
2. Saisissez le **Motif de non-test** tel que les participants le
   voient.
3. Saisissez un **Code Motif** court.
4. Dans **Nom du programme**, sélectionnez chaque programme qui
   propose ce motif.
5. Dans **Recueillir la date de réception du panel ?**, choisissez
   **Oui** ou **Non**.
6. Dans **Statut**, choisissez **Actif**.
7. Cliquez sur **Ajouter**.

Si le motif ou le code est déjà utilisé, la page vous le signale et
vide le champ.

## Rôle des champs

| Champ | Effet |
| --- | --- |
| **Nom du programme** | Les formulaires de réponse de ces programmes proposent le motif. Un motif sans programme n'apparaît dans aucun formulaire |
| **Recueillir la date de réception du panel ?** | **Non** règle **Vous avez reçu le panel PT ?** sur **Non** dans le formulaire de réponse quand le participant choisit ce motif |
| **Statut** | Seuls les motifs **Actif** apparaissent dans les formulaires de réponse |

## La liste des motifs

La liste affiche chaque motif avec son **Code Motif**, ses programmes
dans **Programme disponible**, son réglage **Collecte la date de
réception du panel ?** et son **Statut**.

Utilisez **Nom du programme** au-dessus de la liste pour n'afficher
que les motifs d'un programme.

## Modifier ou retirer un motif

1. Cliquez sur **Edit** dans la ligne du motif.
2. Modifiez les champs.
3. Cliquez sur **Ajouter** pour enregistrer. Le formulaire de
   modification utilise le même libellé de bouton que le formulaire
   d'ajout.

Pour ne plus proposer un motif, réglez son **Statut** sur **Inactif**.
La page n'a pas de bouton de suppression.
