# Paramètres SARS-CoV-2

Cette page définit comment les expéditions SARS-CoV-2 sont testées et
notées.

## Notation

- **Pourcentage minimum de réussite** : le score qu'un participant doit
  obtenir pour réussir.
- **Algorithmes autorisés** : les algorithmes de test que les
  participants peuvent choisir, séparés par des virgules.

## Options de test

- **Nombre maximum de tests autorisés** : le nombre de tests qu'un
  participant peut déclarer pour chaque échantillon.
- **Nombre de jours pour la réhydratation de l'échantillon** : le délai
  que les participants respectent entre la réhydratation et le test.
  Choisissez **Permettre les tests le jour même**, **Test après 1 jour
  seulement** ou **Test après 2 jours seulement**.

## Métadonnées du rapport

La **Version du rapport** et la **Date d'entrée en vigueur du rapport**
s'impriment dans le pied de page de chaque rapport PDF.

## Plateformes de test recommandées

Une réponse qui n'utilise pas l'une des plateformes de test recommandées
ne réussit pas pour cet échantillon.

1. Configurez d'abord les plateformes dans **Plateformes de test
   standard pour le SARS-CoV-2**.
2. Dans **Type de test recommandé**, choisissez les plateformes
   recommandées.

Cliquez sur **Mettre à jour** pour enregistrer. Les modifications
s'appliquent à la prochaine évaluation d'une expédition.
