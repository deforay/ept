# Questions de feedback

Cette page est la bibliothèque de questions. Vous y choisissez des
questions quand vous créez le formulaire de feedback d'une expédition.
Voir [Formulaires de feedback](feedback-forms.md).

## Ajouter une question

1. Cliquez sur **Ajouter une nouvelle question**.
2. Saisissez le texte de la **Question** que voient les participants.
3. Saisissez un **Code de la question** court. Il sert dans les réponses
   téléchargées.
4. Dans **Afficher la question de rétroaction à**, choisissez **Tous les
   participants**, **Seuls les participants ayant réussi** ou **Seuls
   les participants ayant échoué**.
5. Choisissez le **Type de question** : **Texte**, **Numérique**, **Date
   et heure** ou **Liste déroulante**. Pour **Liste déroulante**,
   saisissez chaque choix dans les lignes **Options**.
6. Réglez le **Statut de la question** sur **Actif**.
7. Cliquez sur **Ajouter**.

## Modifier ou retirer une question

Cliquez sur **Modifier** sur la ligne de la question. Pour ne plus
proposer une question, réglez le **Statut de la question** sur
**Inactif**.

Une question inactive disparaît de tous les formulaires, y compris ceux
qui l'utilisent déjà. Ses réponses sont aussi masquées. Ne désactivez
pas une question pendant qu'un formulaire qui l'utilise est ouvert au
feedback.
