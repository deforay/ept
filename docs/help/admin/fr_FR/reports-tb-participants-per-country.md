# Participants TB par pays

**Rapports → TB : Nombre de participants par pays** indique combien de participants chaque pays compte dans les expéditions TB, ainsi que leurs réponses et leurs performances.

Le rapport s'affiche dès l'ouverture de la page. Les filtres s'appliquent dès que vous les modifiez. Il n'y a pas de bouton Obtenir un rapport.

## Filtres

Cliquez sur **Afficher les filtres** pour afficher les filtres. Le rapport couvre uniquement la TB. Il n'y a donc pas de filtre de programme.

| Filtre | Effet | Par défaut |
|---|---|---|
| Date d'expédition | Inclut les expéditions dont la date d'expédition est dans cette période. Cliquez sur **Effacer** dans le sélecteur de dates pour inclure toutes les dates. | 3 dernières années |
| Expédition | Inclut uniquement les expéditions choisies. Vous pouvez en choisir plusieurs. La liste contient toutes les expéditions TB non annulées de la période. | Toutes les expéditions de la période |
| Pays, Région, Province, District | Inclut uniquement les participants de ce lieu. Chaque filtre s'affiche seulement si des participants ont ce champ renseigné. | Tout |

Chaque filtre actif s'affiche sous forme d'étiquette à côté du bouton **Afficher les filtres**.

- Cliquez sur une étiquette pour ouvrir le panneau des filtres sur ce filtre.
- Cliquez sur **×** sur une étiquette pour retirer ce filtre.

Les expéditions annulées n'apparaissent jamais dans ce rapport.

## Graphique

Chaque barre correspond à un pays. La longueur de la barre est le nombre de participants. Les pays qui ont le plus de participants apparaissent en premier.

## Tableau

Chaque ligne correspond à un pays. Un participant inscrit à trois expéditions compte pour un participant et trois inscriptions.

| Colonne | Contenu |
|---|---|
| Pays | Le pays indiqué dans la fiche du participant. Les participants sans pays apparaissent sous **Non défini**, à la fin. |
| Participants | Le nombre de participants. |
| Inscrits | Le nombre d'inscriptions. |
| Répondu | Le pourcentage d'inscriptions avec une réponse, avec une barre. En dessous, le nombre de réponses sur le nombre d'inscriptions. |
| Taux de réussite | Le pourcentage de réponses évaluées qui ont réussi, avec une barre. En dessous, le nombre de réussites sur le nombre de réponses évaluées. Affiche **Pas encore évalué** avant l'évaluation. |
| Échec | Le nombre de réponses en échec. |

Cliquez sur l'en-tête d'une colonne pour trier selon cette colonne.

## Télécharger Excel

**Télécharger Excel** enregistre le tableau dans un fichier Excel, avec le taux de réponse et le taux de réussite en pourcentages. Le fichier reprend les filtres du rapport affiché.
