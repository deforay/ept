# Mon compte

Le menu **Gérer** regroupe les pages de votre compte.

| Page | À quoi elle sert |
| --- | --- |
| **Mes informations de connexion** | Votre nom et vos coordonnées |
| **Informations sur les participants au PT** | Les laboratoires pour lesquels votre identifiant saisit des résultats |
| **Informations sur le programme** | Les programmes auxquels participe chacun de vos laboratoires |
| **Modifier l'adresse e-mail principale** | Changer l'adresse e-mail de connexion |
| **Modifier le mot de passe** | Définir un nouveau mot de passe |

## Changer votre mot de passe

1. Ouvrez **Gérer → Modifier le mot de passe**.
2. Vérifiez que le laboratoire affiché est le vôtre. Cliquez sur
   **Oui, continuer**. Sinon, cliquez sur **Ce n'est pas moi, me
   déconnecter**.
3. Saisissez votre **Ancien mot de passe**.
4. Saisissez deux fois le **Nouveau mot de passe**. Vous ne pouvez
   pas réutiliser un ancien mot de passe.

## Changer votre adresse e-mail de connexion

1. Ouvrez **Gérer → Modifier l'adresse e-mail principale**.
2. Saisissez votre adresse e-mail actuelle, puis deux fois la
   nouvelle adresse.
3. Cliquez sur **Modifier l'adresse e-mail**.
4. Ouvrez le lien qu'ePT envoie à la nouvelle adresse. Le
   changement ne prend effet qu'après l'ouverture du lien.

## Questions fréquentes

- **Un laboratoire manque dans Informations sur les participants au
  PT.** Votre identifiant n'est pas lié à ce laboratoire. Demandez
  à votre fournisseur PT de le lier.
- **J'ai oublié mon mot de passe.** Déconnectez-vous, puis cliquez
  sur **Mot de passe oublié ?** sur la page de connexion.
