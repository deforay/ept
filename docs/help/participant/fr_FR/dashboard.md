# Tableau de bord

Le tableau de bord est la première page affichée après la
connexion.

## Contenu de la page

- **Que souhaitez-vous faire aujourd'hui ?** : quatre liens
  rapides : **Réponse à l'expédition**, **Rapport individuel**,
  **Rapports de synthèse** et **Modifier le profil**.
- **Expéditions en attente de vos résultats** : chaque expédition
  qui attend encore vos résultats, avec sa date limite. Les
  expéditions marquées **Échéance proche** se ferment en premier.
  Cliquez sur **Saisir les résultats** pour ouvrir le formulaire
  de résultats. Si une expédition affiche **Terminer votre
  brouillon**, vous l'avez commencée et avez enregistré un
  brouillon.
- **Vos résultats récents** : votre dernier score pour chaque
  programme. Les résultats n'apparaissent ici qu'après la
  finalisation de l'expédition par le fournisseur PT.

Si la liste d'attente indique *Vous êtes à jour. Aucune expédition
n'attend vos résultats.*, vous n'avez rien à faire pour le moment.

## Questions fréquentes

- **Une expédition attendue n'est pas dans la liste.** Le
  fournisseur PT ne l'a pas encore expédiée, ou votre laboratoire
  ne fait pas partie de cette expédition. Contactez votre
  fournisseur PT.
- **Mon score n'apparaît pas.** Les scores apparaissent après la
  finalisation de l'expédition. D'ici là, le fournisseur PT vérifie
  encore les résultats.
