# Actions correctives

Une action corrective indique à votre laboratoire ce qu'il doit
corriger après un résultat non conforme.

## Voir les actions correctives d'une expédition

1. Ouvrez **Actions correctives**.
2. Choisissez une période dans **Date d'expédition** et un
   **Programme**. Cliquez ensuite sur **Obtenir un rapport**.
3. Trouvez l'expédition grâce à son **Code de l'expédition**. La
   colonne **Action corrective** indique ce qu'il faut faire.

## CAPA

**CAPA** (action corrective et préventive) n'apparaît dans le menu
que si votre fournisseur PT l'a activé. Cette page liste vos
expéditions avec leur **Résultat final**. Cliquez sur **Action**
sur la ligne d'une expédition pour consigner ce que votre
laboratoire a fait pour corriger le problème.

Pour enregistrer la liste dans un fichier, cliquez sur **Exporter
le rapport**.
