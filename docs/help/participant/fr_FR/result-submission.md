# Soumettre les résultats PT

Cette page liste les expéditions de votre laboratoire. C'est ici
que vous saisissez vos résultats.

## Saisir vos résultats

1. Trouvez l'expédition grâce à son code dans la colonne
   **Expédition**. Vérifiez le nom du **Participant** sur la même
   ligne.
2. Vérifiez la **Date limite de soumission des résultats**. Après
   cette date, vous ne pouvez plus modifier la réponse.
3. Cliquez sur **Saisir la réponse**.
4. Remplissez le formulaire. Saisissez les dates, les kits de test
   utilisés et le résultat de chaque échantillon.
5. Cliquez sur **Envoyer**.
6. Si une page de vérification s'ouvre, contrôlez vos réponses.
   Cliquez ensuite sur le bouton vert **Confirmer la réponse** en
   bas de la page.

Votre réponse **n'est pas enregistrée** tant que vous n'avez pas
cliqué sur **Confirmer la réponse**. Si la ligne affiche encore
**Saisir la réponse**, la réponse n'a pas été enregistrée.
Ouvrez-la de nouveau et terminez.

## Les boutons de chaque ligne

| Bouton | Signification |
| --- | --- |
| **Saisir la réponse** | Vous n'avez pas encore envoyé de résultats pour cette expédition |
| **Voir / modifier** | Vous avez envoyé des résultats. Ouvrez-les pour les vérifier ou les modifier avant la date limite |
| **Afficher/Modifier le brouillon** | Vous avez enregistré un brouillon (formulaire TB uniquement). Ouvrez-le et terminez |
| **Supprimer la réponse** | Supprime votre réponse pour vous permettre de recommencer |

## Si vous n'avez pas pu tester le panel

Ouvrez le formulaire de résultats et cochez **Panel PT non testé**.
Indiquez ensuite la raison. Ne saisissez pas de résultats négatifs
pour des échantillons que vous n'avez pas testés.

## Autres listes du menu

- **Tous les programmes** : toutes les expéditions de votre
  laboratoire, y compris les anciennes.
- **Programmes sans réponse** : les expéditions dont la date limite
  est dépassée.

## Questions fréquentes

- **L'expédition n'est pas dans la liste.** Le fournisseur PT ne
  l'a pas encore expédiée, ou votre laboratoire ne fait pas partie
  de cette expédition. Contactez votre fournisseur PT.
- **Je ne peux pas modifier ma réponse.** La date limite est
  dépassée, ou l'expédition est finalisée. Contactez votre
  fournisseur PT.
