# Téléchargements

Cette page liste les fichiers que votre fournisseur PT a partagés
avec votre laboratoire. Par exemple : les instructions d'un cycle,
des formulaires et des certificats.

Chaque ligne affiche l'**Identifiant unique du participant**, le
**Nom du participant** et la date dans **Partagé le**. Cliquez sur
**Télécharger** pour enregistrer le fichier.

Si un fichier attendu n'apparaît pas ici, contactez votre
fournisseur PT. Le fournisseur décide des fichiers que reçoit
chaque laboratoire.
