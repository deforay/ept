# Consulter vos rapports

Les rapports ne sont disponibles qu'après la **finalisation** de
l'expédition par le fournisseur PT. Avant cela, la liste est vide
pour cette expédition.

## Rapport individuel

Le résultat et le score de votre laboratoire pour une expédition.

1. Ouvrez **Voir le résultat du PT → Rapport individuel**.
2. Pour réduire la liste, choisissez une période dans **Date
   d'expédition** ou un **Programme**. Cliquez ensuite sur
   **Obtenir un rapport**.
3. Trouvez votre expédition grâce à son **Code de l'expédition**.
4. Cliquez sur le lien de la colonne **Rapport** pour télécharger
   le PDF.

Pour télécharger plusieurs rapports à la fois, cochez-les et
cliquez sur **Télécharger les rapports sélectionnés**.

## Rapport de synthèse

Les résultats globaux d'une expédition pour l'ensemble des
laboratoires.

1. Ouvrez **Voir le résultat du PT → Rapport de synthèse**.
2. Choisissez une période dans **Date d'expédition** et un
   **Programme**. Cliquez ensuite sur **Obtenir un rapport**.
3. Cliquez sur le lien de la colonne **Rapport**.

## Questions fréquentes

- **Mon rapport n'est pas dans la liste.** L'expédition n'est pas
  encore finalisée. Contactez votre fournisseur PT si la date
  limite de soumission des résultats est dépassée depuis longtemps.
- **Le résultat indique Insatisfaisant.** Lisez le rapport pour
  repérer les échantillons non conformes. Consultez ensuite
  **Actions correctives**.
