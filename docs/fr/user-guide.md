# Comment réaliser les tâches courantes dans ePT

[English](../user-guide.md)

Utilisez ce guide pour trouver la procédure adaptée à votre rôle dans ePT 7.6.21.
Les menus visibles dépendent des privilèges du compte et des fonctions activées.

## Avant de commencer

Obtenez un compte auprès de votre fournisseur PT. Confirmez les participants associés à votre compte.
Utilisez l'URL de l'installation du fournisseur et le rôle attribué.
Un participant représente un laboratoire, un site ou un opérateur.
Un gestionnaire de données est un compte pouvant agir pour les participants associés.
Pour créer un compte ou examiner les accès, consultez la [gestion des utilisateurs](user-management.md).

## Gérer un cycle PT en tant qu'administrateur

1. Suivez la [configuration et gestion des participants, en anglais](../training/part1-setup-and-participants.md), pour enregistrer les comptes et les participants.
2. Suivez les [enquêtes et expéditions, en anglais](../training/part2-surveys-and-shipments.md), pour créer le cycle et inscrire les participants.
3. Examinez les réponses et exceptions selon le guide d'[évaluation et rapports, en anglais](../training/part4-evaluation-and-reports.md).
4. Vérifiez le contenu des rapports générés avant la finalisation.
5. Confirmez qu'un compte associé au participant peut télécharger le rapport publié.

## Soumettre des résultats en tant que gestionnaire de données

1. Connectez-vous au portail participant.
2. Ouvrez **Envoi des résultats du PT**.
3. Sélectionnez le bon participant et la bonne expédition.
4. Vérifiez la date d'échéance affichée et les identifiants des échantillons.
5. Saisissez les résultats et champs justificatifs selon la [procédure participant, en anglais](../training/part3-participant.md).
6. Terminez toute étape de confirmation affichée par le formulaire.
7. Rouvrez la réponse ou son état pour confirmer l'enregistrement des valeurs prévues.

Si le test n'a pas été réalisé, utilisez la déclaration correspondante lorsqu'elle est disponible.
Ne remplacez pas un test non réalisé par un résultat négatif.
Si l'expédition est fermée ou si une réponse tardive attend une approbation, contactez le fournisseur PT.

## Trouver les rapports et les informations du compte

Les libellés ci-dessous correspondent au catalogue français livré.
Certains menus emploient encore « régime » pour désigner un programme.

| Menu | Tâche |
| --- | --- |
| Tableau de bord | Consulter la vue d'ensemble PT du compte |
| Envoi des résultats du PT | Trouver les résultats à saisir |
| Voir le résultat du PT → Rapport individuel | Trouver le rapport disponible d'un participant |
| Voir le résultat du PT → Rapport de synthèse | Trouver les rapports récapitulatifs disponibles |
| Actions correctives | Consulter les éléments d'action corrective disponibles |
| CAPA | Ouvrir le processus d'action corrective lorsqu'il est activé |
| Tous les régimes | Consulter la liste élargie des expéditions |
| Régimes en défaut | Consulter la liste des expéditions en défaut |
| Gérer → Mes informations de connexion | Consulter les informations du compte de connexion |
| Gérer → Informations sur les participants au PT | Consulter les informations des participants associés |
| Gérer → Informations sur le régime | Consulter les informations du programme |

Les comptes PTCC peuvent disposer de menus supplémentaires de gestion des participants et gestionnaires de données.
En cas de données absentes, faites vérifier les associations et inscriptions avant de créer des doublons.

## Vérifier un rapport

1. Ouvrez le rapport depuis le compte participant prévu.
2. Confirmez l'identifiant du participant et le code d'expédition.
3. Comparez les résultats du rapport avec la réponse soumise.
4. Signalez les écarts au fournisseur PT en indiquant le code d'expédition et l'identifiant du participant.

Pour un cycle d'entraînement, utilisez l'[exercice DTS, en anglais](../training/exercises/dts-hiv-serology.md).
Pour les incidents opérationnels, consultez le [dépannage](troubleshooting.md).
