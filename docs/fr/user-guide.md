# Comment réaliser les tâches courantes dans ePT

Utilisez ce guide pour trouver la procédure adaptée à votre rôle dans ePT.
Les menus visibles dépendent des privilèges du compte et des fonctions activées pour le programme.

## Avant de commencer {#before-you-start}

Obtenez un compte auprès de votre fournisseur PT. Confirmez les participants associés à votre compte.
Utilisez l'URL de l'installation du fournisseur et le rôle attribué.
Un participant représente un laboratoire, un site ou un opérateur. Un gestionnaire de données est un compte
qui peut agir pour les participants associés.
Pour créer un compte ou examiner les accès, consultez la [gestion des utilisateurs](user-management.md).

## Gérer un cycle PT en tant qu'administrateur {#run-a-pt-round-as-an-administrator}

1. Suivez la [configuration et gestion des participants](training/part1-setup-and-participants.md) pour enregistrer les comptes et les participants.
2. Suivez les [enquêtes et expéditions](training/part2-surveys-and-shipments.md) pour créer le cycle et inscrire les participants.
3. Examinez les réponses reçues et les exceptions avec le guide d'[évaluation et rapports](training/part4-evaluation-and-reports.md).
4. Vérifiez le contenu des rapports générés avant la finalisation.
5. Confirmez qu'un compte associé au participant peut télécharger le rapport publié.

## Soumettre des résultats en tant que gestionnaire de données {#submit-results-as-a-data-manager}

1. Connectez-vous au portail participant.
2. Ouvrez **Envoi des résultats du PT**.
3. Trouvez l'expédition par son code d'expédition. Vérifiez le nom du participant sur la même ligne.
4. Cliquez sur **Saisir la réponse**.
5. Vérifiez la date limite affichée et les identifiants des échantillons.
6. Saisissez les résultats et les champs justificatifs selon la [procédure participant](training/part3-participant.md).
7. Cliquez sur **Envoyer**.
8. Si une page de vérification s'ouvre, vérifiez les réponses. Cliquez ensuite sur le bouton vert **Confirmer la réponse** en bas de la page. La réponse n'est enregistrée qu'après cette confirmation.
9. Rouvrez la réponse ou son état pour confirmer l'enregistrement des valeurs prévues.

Si le test n'a pas été réalisé, utilisez la déclaration « non testé » du formulaire lorsqu'elle est disponible.
Ne remplacez pas un test qui n'a jamais été réalisé par un résultat négatif.
Si l'expédition est fermée ou si une réponse tardive attend une approbation, contactez le fournisseur PT.

## Trouver les rapports et les informations du compte {#find-reports-and-account-information}

| Menu | Tâche |
| --- | --- |
| Tableau de bord | Consulter la vue d'ensemble PT du compte |
| Envoi des résultats du PT | Trouver les résultats à saisir |
| Voir le résultat du PT → Rapport individuel | Trouver le rapport disponible d'un participant |
| Voir le résultat du PT → Rapport de synthèse | Trouver les rapports de synthèse disponibles |
| Actions correctives | Consulter les éléments d'action corrective disponibles |
| CAPA | Ouvrir le processus d'action corrective lorsqu'il est activé |
| Tous les programmes | Consulter la liste élargie des expéditions |
| Programmes sans réponse | Consulter la liste des expéditions sans réponse |
| Gérer → Mes informations de connexion | Consulter les informations du compte de connexion |
| Gérer → Informations sur les participants au PT | Consulter les informations des participants associés |
| Gérer → Informations sur le programme | Consulter les informations du programme |

Les comptes PTCC peuvent disposer de menus supplémentaires pour gérer les gestionnaires de données et les participants.
En cas de données absentes, demandez au fournisseur de vérifier les associations et les inscriptions avant de créer des doublons.

## Vérifier un rapport {#verify-a-report}

1. Ouvrez le rapport depuis le compte participant prévu.
2. Confirmez l'identifiant du participant et le code d'expédition.
3. Comparez les résultats du rapport avec la réponse soumise.
4. Signalez les écarts au fournisseur PT en indiquant le code d'expédition et l'identifiant du participant.

Pour un cycle d'entraînement, utilisez l'[exercice DTS](training/exercises/dts-hiv-serology.md).
Pour les incidents opérationnels, consultez le [dépannage](troubleshooting.md).
